# 45. 아군 무기 분화 — 손 구성이 무기 종류를 정한다 (Party Weapons)

> **상태**: 초안 (2026-09-06). **일부 구현됨 (2026-09-09, W1-06)** — 아래 §7 참조.
> 원거리 넷과 손 구성 넷이 전투 무기 표에 들어갔고, 손 구성이 만드는 상시 값 넷
> (`strikes` · 도포 칸 · 회피 · 선제)이 규격 v4 로 건너간다. **고유 동작
> (기세 · 받아치기 · 변형 강타 · 거치 · 돌격 밀기)은 아직 없다.** [BP-44](44_bestiary.md) 가 적을 갈랐듯
> 이 장은 아군의 무기를 가른다. 둘은 서로 독립이다.
> **소유 주제**: 아군 무기 종류(kind) · 손 구성 규칙 · 종류별 사거리·방식·고유 동작 · 장비 슬롯 규칙의
> 변경. 무기 **아이템 데이터**(이름·값·획득처)는 [BP-42](42_item_and_inventory.md) 가 소유한다.

## 0. 지금 상태

**전투 쪽** — 무기는 `weaponKey` 하나로 `WeaponProfile` 을 고른다(`rules/weapon.dart`, B5-02). 한 profile 은
방식(`WeaponAttack`) 1~2개이고, 방식마다 **속성**(베기·찌르기·타격) · **사거리 하한~상한** · **위력 %** ·
**돌격 가능**이 있다. 12 키 — 맨손 · 단도 · 곤봉 · 철퇴 · 지팡이 · 장검 · 화염검 · 미늘창 · 도끼창 · 삼지창 ·
기병창 · 대검. 긴 무기는 자루(약한 타격 0~1)를 두 번째 방식으로 가져 **헛턴이 없다**(B5 불변식).
RPG 는 `powOfWeapon`(얼마나 센지)만 넘기고 전투가 닿는 법을 정한다.

**RPG 쪽** — 슬롯은 `hand` + `handSub`(**방패 전용**) + 갑옷·투구·신발·장식. 방패는 `ac × 5` 가 막을
확률(`shieldBlock`, 최대 75)이 되어 회피에 접힌다(B5-05). 버팀은 첫 피격 +45 · 두 번째 +12(B5-03).
무기 카탈로그는 C++ 의 10종뿐이다(`item_data.dart`).

**원작에 이미 있는 것** — Unity 포트 `ObjItem.cs:405-441` 의 `WEAPON_LIST` 는 **5갈래 × 7 = 31종**이다:

| 갈래 (`ITEM_TYPE`) | 원작 7종 |
|---|---|
| 베는 무기 (WIELD) | 단검 · 그라디우스 · 샤벨 · 신월도 · 인월도 · 장검 · 프렘버그 |
| 찍는 무기 (CHOP) | 소형 해머 · 소형 도끼 · 프레일 · 전투용 망치 · 철퇴 · 양날 전투 도끼 · 핼버드 |
| 찌르는 무기 (STAB) | 단도 · 기병창 · 단창 · 레이피어 · 삼지창 · 랜서 · 도끼창 |
| 타격 무기 (HIT) | 너클 · 장대 · 곤봉 |
| **쏘는 무기 (SHOOT)** | **블로우 파이프 · 표창 · 투석기 · 투창 · 활 · 석궁 · 아르발레스트** |

**원작에 원거리 무기가 일곱 개 있다.** 우리 규칙에는 하나도 없다(BP-44 §7.4 의 "사격 — 없음" 이 그것이다).
그리고 이름이 이미 손 구성을 말한다 — 프렘버그·양날 전투 도끼·핼버드·랜서는 양손, 단검·소형 도끼·
레이피어는 한손, 장대는 봉이다. 손 구성이 이 장의 축이다.

## 1. 원칙

1. **무기 종류는 장비에서 유도된다. 새 슬롯은 없다.** 주손 아이템의 갈래 + 보조손에 든 것(없음·방패·같은
   갈래의 한손 무기·양손 무기의 나머지 손) → 종류. G1 의 부위 체계와 B5-02 의 "보조 무기 슬롯을 만들지
   않는다" 판정을 그대로 지킨다. 플레이어는 지금처럼 물건을 끼고, **종류는 결과로 나타난다.**
2. **종류가 정하는 것은 넷** — 방식(사거리·속성·위력) · 고유 동작(있으면 하나) · 상시 효과 · 도포 칸 수.
   `powOfWeapon` 은 여전히 RPG 의 것이다.
3. **B5 불변식 안에서.** 모든 종류가 거리 0 에서 무언가를 한다. 자세 전환에 턴을 쓰게 하지 않는다 —
   변형은 거리가 정하고, 거치는 사격에 딸려 온다. DQ 의 라운드(전원 명령 → 일괄 해결)를 건드리지 않는다.
4. **이름은 표준어.** 종류 이름은 일상어·원작 이름표에서 가져온다 — 석궁·아르발레스트·전투 망치·장봉·대검.
   외부 게임의 고유 용어는 쓰지 않는다.

## 2. 손 구성 → 무기 종류

```
주손 갈래 × 보조손  →  종류
```

| 주손 | 보조손 | 종류 | 한 줄 |
|---|---|---|---|
| 한손 베는·찍는·찌르는·타격 | **없음** | **한손** (경장) | 가볍다. 회피·선제가 오른다. 방식은 물건의 갈래를 따른다 |
| 한손 베는·찍는·타격 | **방패** | **검과 방패** | 표준. 방패 치기가 타격 방식을 준다 |
| 한손 찌르는 (창) | **방패** | **창과 방패** | 사거리 1~2 찌르기 + 버팀이 강하고 **받아친다** |
| 한손 X | **같은 갈래 한손 X** | **쌍수** | 두 번 친다. 칼마다 **도포가 따로** 붙는다. 쌍검·쌍도끼·쌍곤봉 |
| 양손 베는 (프렘버그·장검) | — | **대검** | 크게 벤다. 연속 명중이 **기세**를 쌓는다 |
| 양손 찍는 — 타격 (전투용 망치) | — | **전투 망치** | 어디서든 **돌격**하고, 돌격 명중은 반드시 밀어낸다 |
| 봉 (장대·지팡이) | — | **장봉** | 0~2 전부 정위력. 전투승의 무기 |
| 양손 창·도끼 (핼버드·도끼창·양날 전투 도끼·삼지창) | — | **장병기** | 멀면 창, 붙으면 **도끼로 변형** — 거리가 정한다 |
| 기병창 (랜서) | — | **기병창** | 2~3 돌격 특화. 지금 `lance` 그대로 |
| 활 | — | **활** | 뒷열에서 1~3. 화살에 도포가 붙는다 |
| 석궁 | — | **석궁** | 0~3 어디서든 쏜다. 위력은 낮다 |
| 아르발레스트 | — | **아르발레스트** | 2~3 강력. **거치**하면 더 세진다 |
| 표창·투창·투석기·블로우 파이프 | 없음·방패 | **투척** | 한손 원거리 1~2. 방패와 같이 든다 |
| 악기 | — | **악기** | (보류 §3.14) |

표에 없는 조합은 **불가**다 — 방패 + 양손 무기, 갈래가 다른 두 한손 무기, 방패 + 활. 장비 화면이 막는다(§4.1).

### 왜 이 축인가

원작 다섯 갈래는 **속성**(베기·찍기·찌르기·타격·사격)이고, B5-02 가 이미 그것을 방식으로 옮겼다. 그 위에
손 구성을 얹으면 같은 갈래 안에서 **성격이 갈린다** — 한손 검은 빠르고, 검과 방패는 버티고, 쌍검은 두 번
치고, 대검은 크게 벤다. 위력 사다리(`powOfWeapon`)와 무관한 축이라, 같은 값의 무기라도 **다른 이유로**
고르게 된다. 이것이 B5-02 가 "단도를 남겨 둘 이유" 라고 부른 것의 나머지 절반이다.

## 3. 종류별 명세

값은 잠정이고 표기는 `속성 하한~상한 (위력%)` 이다. `powOfWeapon` 은 RPG 가 준 그대로 곱해진다.
**모든 종류의 방식 묶음이 거리 0 을 덮는다** — 이것을 `purity_test` 가 확인한다(§5).

### 3.1 한손 (경장)

| | |
|---|---|
| 방식 | 물건의 갈래대로 0~1 (100). 베는 → 베기, 찌르는 → 찌르기, 찍는·타격 → 타격 |
| 상시 | **회피 +4 · 선제 +5.** 손이 비어 있어 몸이 가볍다 |
| 버팀 | 방패 보너스가 없다 — 몸으로만 버틴다 |
| 도포 | 1 |

"한손에 드는 무기 → 그만큼 민첩해짐". 방패의 값(`ac 5` 방패 = 회피 +12)보다 **눈에 띄게 작게** 잡아
방패를 버리는 선택이 되게 한다 — 회피는 반, 선제는 방패에 없는 것.

### 3.2 검과 방패

| | |
|---|---|
| 방식 1 | 물건의 갈래대로 0~1 (100) |
| 방식 2 | **방패 치기** — 타격 0 (55). 약점이면 밀어낸다(B5-07 의 타격 규칙 그대로) |
| 상시 | 방패 `shieldBlock` (지금과 같음) |
| 버팀 | 지금과 같음 (+45 / +12) · 밀림 면역 |
| 도포 | 1 |

검에 없던 **타격 방식**이 방패에서 온다. 그래서 언데드·골렘 앞에서도 검사가 할 일이 생긴다 — 약하지만
밀어낸다. 방식 선택은 `chooseAttack` 이 하므로 메뉴는 늘지 않는다.

### 3.3 창과 방패

| | |
|---|---|
| 방식 1 | 찌르기 1~2 (100) |
| 방식 2 | 자루 — 타격 0 (60) |
| 고유 | **받아치기** — 버틴 상태에서 근접 공격을 받으면 그 라운드 안에 찌르기 (70) 로 한 번 되돌려준다. 라운드에 한 번 |
| 버팀 | **+60 / +20** — 방패 종류 중 가장 단단하다 |
| 돌격 | 가능 (1열까지) |
| 도포 | 1 |

앞열의 벽이면서 가만히 서 있지 않는다. 받아치기는 **버팀을 고른 사람에게 공격 기회를 돌려주는** 장치라,
"버팀 = 그 턴을 버림" 이 아니게 된다. 원작 이름표의 랜서·단창이 여기 온다.

### 3.4 쌍수

| | |
|---|---|
| 방식 | 물건의 갈래대로 0~1 — **두 번**, 각 (55). 명중·그레이즈를 따로 굴린다 |
| 상시 | 회피 +2 (한손보다 작다 — 손이 둘 다 차 있다) |
| 고유 | **두 칼, 두 도포.** 주손·보조손 도포가 따로 붙는다 — 독 + 화염 |
| 버팀 | 방패 보너스 없음 |
| 밀림 | 타격 쌍수(쌍곤봉)는 한 행동에 **한 번만** 밀어낸다 — 두 번 밀면 열이 라운드마다 무너진다 |
| 도포 | **2** |

두 번 굴리므로 기대값은 110% 로 같지만 **편차가 작다** — 큰 한 방이 아니라 꾸준한 것. 둘 다 빗나가는 일도
둘 다 크리티컬인 일도 드물다. 도포 둘이 이 종류의 이유다: 마비로 멈추고 독으로 깎는다.
쌍도끼·쌍곤봉은 **같은 규칙**이고 속성만 다르다 — 갈래가 같으면 뭐든 짝이 된다.

### 3.5 대검

| | |
|---|---|
| 방식 1 | 베기 1~2 (115) · 돌격 가능 (지금 `great_sword`) |
| 방식 2 | 자루·손잡이 — 타격 0 (60) |
| 고유 | **기세** — 명중할 때마다 +10%, 최대 3 (145%). **피격되면 0.** 라운드를 넘어 유지된다 |
| 버팀 | 방패 없음. 버티면 기세가 지켜진다(맞아도 안 깎임) |
| 도포 | 1 |

"태도" 의 느낌 — 계속 베면 점점 세지고, 한 번 맞으면 처음부터. 뒷열에 서서 앞열이 막아 주면 기세가 산다.
그래서 **위치와 엮인다** — 대검은 2열에서 사거리 1~2 로 앞을 넘겨 베는 무기다.

### 3.6 전투 망치

| | |
|---|---|
| 방식 | 타격 0~1 (120) · **돌격 가능** |
| 고유 | **돌격 명중은 반드시 밀어낸다** — 약점 판정 없이. 밀 곳이 없으면 구석 보너스(+50%) |
| 상시 | 선제 −3. 무겁다 |
| 도포 | 1 |

지금 돌격은 기병창·대검만 한다. 망치의 돌격은 **위치를 바꾸는 돌격**이다 — 적 앞열을 밀어내 대열을 흔든다.
"이동 차지" 가 이것이다. 원작의 전투용 망치·양날 전투 도끼가 여기 온다(도끼는 베기 — 그 경우 밀어내기가
없으므로 도끼는 §3.8 장병기로 보낸다. 표를 분명히 하자면 **찍는 양손 = 타격이면 망치, 베기면 장병기**).

### 3.7 장봉

| | |
|---|---|
| 방식 | 타격 0~2 (85). **하한 0, 상한 2, 위력이 거리에 따라 변하지 않는다** |
| 상시 | 회피 +4 |
| 고유 | 없음 — 어느 거리에서나 같은 것이 고유다 |
| 도포 | 1 |

지금 `staff` 가 거의 이것이다(0~2, 80). 벌레 요소 없이 **전투승의 장봉**. 다른 모든 무기가 거리로 위력이
갈리는데 이것만 평평해서, 대열이 흔들리는 전투(밀림·돌격이 많은)에서 값이 난다. 봉과 타격 40~100 의
전투승(BP-44 §7.4)이 자연히 맞는다.

### 3.8 장병기 — 변형

| | |
|---|---|
| 방식 1 | **창 형태** — 찌르기 1~2 (100) |
| 방식 2 | **도끼 형태** — 베기 0~1 (95). 자루가 아니라 **머리**로 친다 |
| 고유 | **변형 강타** — 창 형태로 거리 ≥1 에서 명중한 직후, 다음 도끼 형태 명중이 +30% |
| 돌격 | 가능 |
| 도포 | 1 |

지금 미늘창·도끼창·삼지창은 두 번째 방식이 **약한 자루(60)** 다 — 붙으면 나쁜 무기가 된다. 변형은 그 자리에
**정위력의 다른 속성**을 넣는 것이다: 멀면 찌르고(갑각에 약함) 붙으면 벤다(살에 강함). **거리가 형태를 정하므로
턴을 쓰지 않는다** — B5 불변식을 지키면서 "붙어 오면 도끼로 바꾼다" 는 기믹이 된다. 변형 강타는 두 형태를
번갈아 쓰게 하는 작은 보상이고, 없어도 성립한다(선택).

삼지창은 창 형태만 강하고 도끼 형태가 없으니 **자루(60)** 를 유지한다 — 변형은 도끼 머리가 있는 것만.

### 3.9 기병창

지금 `lance` 그대로 — 찌르기 2~3 (120) 돌격 · 자루 타격 0~1 (50). 돌격해서 크게 찌르고, 붙으면 자기가 약해진다
(B5-02). 유일하게 사거리 3 이 있다. 바꾸지 않는다.

### 3.10 활

| | |
|---|---|
| 방식 1 | 찌르기 1~3 (90) |
| 방식 2 | 활대 — 타격 0 (40) |
| 상시 | 뒷열에서 대상 가중이 **평평하다** — `falloffForReach(3)` 이 이미 그렇게 준다. 사실상 대상을 고른다 |
| 고유 | **도포가 화살에 붙는다** — 독화살·불화살. 거리에서 독을 건다 |
| 도포 | 1 |

원거리의 값은 **뒷열에서 앞을 넘겨 친다**는 것이고, 대가는 **붙으면 활대밖에 없다**는 것이다. 간격이 0 이 되고
적이 앞열을 뚫으면 궁수는 약해진다 — 앞열이 필요한 이유가 생긴다. 사냥꾼(쏘는 무기 40~100)의 무기.

### 3.11 석궁

| | |
|---|---|
| 방식 | 찌르기 **0~3** (85) |
| 고유 | 없음 — 어디서든 쏘는 것이 고유다 |
| 상시 | 선제 −2 (장전) |
| 도포 | 1 |

활의 반대 — 위력은 낮고 어디서나 쏜다. 붙어도 헛턴이 없는 원거리. 장봉이 근접에서 하는 일을 원거리에서 한다.

### 3.12 아르발레스트

| | |
|---|---|
| 방식 1 | 찌르기 2~3 (130) |
| 방식 2 | 몸통 — 타격 0~1 (45) |
| 고유 | **거치** — 그 라운드에 자기 열이 바뀌지 않았고 3열이면 +25%. 밀리거나 이동하면 풀린다 |
| 상시 | 선제 −5. 무겁다 |
| 도포 | 1 |

"앉아 쏘기" — 뒷열에 자리 잡고 움직이지 않으면 가장 센 원거리다. 그래서 상대의 **밀어내기가 이 사람에게
의미가 생긴다**(구석에 몰리면 거치가 풀린다). 거치는 행동이 아니라 **상태**다 — 턴을 쓰지 않는다.

### 3.13 투척

| | |
|---|---|
| 방식 1 | 표창·투창 → 찌르기 1~2 (70) · 투석기 → 타격 1~2 (70) |
| 방식 2 | 손 — 타격 0 (40) |
| 보조손 | **방패 허용** — 한손이다 |
| 고유 | 블로우 파이프는 **도포 전용** — 피해 없이 도포 효과만, 저항 판정 없이 건다 |
| 도포 | 1 |

방패를 들고 던지는 중열 무기. 블로우 파이프는 무기라기보다 **도포를 확실히 거는 도구**라, 마비를 반드시
넣어야 하는 전투의 답이 된다.

### 3.14 악기 — 보류

"수렵피리 → bard 급의 악기" 는 **연주 = 파티 전체 버프(명중·회피 +n, 3 라운드)** 가 되어야 하는데, 지금
전투에는 파티 버프 상태가 없다(도포는 개인 상태다). 새 상태 하나와 새 동작 하나가 필요하고, 원작 이름표에
악기가 없다. **보류**한다 — 종류 표에 자리만 둔다. 아이디어가 서면 그때.

### 3.15 한눈에

| 종류 | 손 | 사거리 | 위력 | 고유 | 상시 | 도포 |
|---|---|---|---|---|---|---|
| 한손 | 한 | 0~1 | 100 | — | 회피 +4 · 선제 +5 | 1 |
| 검과 방패 | 한+방패 | 0~1 | 100 / 방패 치기 55 | 방패 치기(타격·밀기) | 방패 | 1 |
| 창과 방패 | 한+방패 | 1~2 | 100 / 자루 60 | 받아치기 · 버팀 +60/+20 | 방패 | 1 |
| 쌍수 | 한+한 | 0~1 | 55 ×2 | 도포 둘 | 회피 +2 | **2** |
| 대검 | 양 | 1~2 | 115 → 145 | 기세 3단 · 돌격 | — | 1 |
| 전투 망치 | 양 | 0~1 | 120 | 돌격 = 반드시 밀기 | 선제 −3 | 1 |
| 장봉 | 양 | 0~2 | 85 평평 | — | 회피 +4 | 1 |
| 장병기 | 양 | 1~2 / 0~1 | 100 / 95 | 변형(거리) · 변형 강타 · 돌격 | — | 1 |
| 기병창 | 양 | 2~3 | 120 / 자루 50 | 돌격 | — | 1 |
| 활 | 양 | 1~3 | 90 / 활대 40 | 화살 도포 | 대상 가중 평평 | 1 |
| 석궁 | 양 | 0~3 | 85 | — | 선제 −2 | 1 |
| 아르발레스트 | 양 | 2~3 | 130 → 155 | 거치 | 선제 −5 | 1 |
| 투척 | 한(+방패) | 1~2 | 70 / 손 40 | 블로우 파이프 = 도포 전용 | 방패 가능 | 1 |

**빈 곳이 없다** — 모든 행이 거리 0 에서 무언가를 한다. 방패가 있는 것은 셋, 사거리 3 은 셋, 돌격은 넷.
같은 갈래(찌르는)가 창과 방패 · 장병기 · 기병창 · 투척 넷으로 갈리는 것이 이 장이 하는 일이다.

## 4. 무엇을 바꿔야 하나

### 4.1 RPG — 아이템에 손 정보, 슬롯에 규칙

`HDItem` 에 **손** 하나가 는다: `hands: one | two`. 갈래는 `HDItemType` 이 이미 갖고 있다(베는·찍는·
찌르는·타격·쏘는). 봉·기병창·활·석궁·아르발레스트·블로우 파이프는 갈래 안의 **모양**이라 `shape` 하나가
더 필요하다 — `blade · axe · spear · club · staff · lance · bow · crossbow · arbalest · thrown · pipe`.
두 값으로 §2 의 종류가 전부 유도된다.

`handSub` 슬롯 규칙(지금은 방패 전용):

| 주손 | 보조손에 넣을 수 있는 것 |
|---|---|
| 한손 무기 | 방패 · **같은 갈래의 한손 무기** · 없음 |
| 투척 | 방패 · 없음 |
| 양손 무기 | **없음** — 슬롯이 잠긴다(화면에 "양손" 표시) |
| 맨손 | 방패 |

**왼손에는 횃불도 들어간다** — 슬롯 여덟 전체와 밝기 규칙은 [BP-47](47_equipment_and_traversal.md) 이 정한다.

장비 화면(G1-07)이 이 표로 후보를 거른다. 잠긴 슬롯은 회색이다. 저장 파일에는 두 슬롯의 아이템 id 가
그대로 들어가므로 **세이브 포맷은 바뀌지 않는다.**

### 4.2 다리 — 종류 유도

`battle_bridge/weapon_mapping.dart` 의 `weaponKeyOf(hand)` 가 `weaponKindOf(hand, handSub)` 가 된다.
`weaponKey` 는 규격에서 **문자열 그대로**고 값의 어휘만 바뀐다 — `'one_hand_slash'` · `'sword_shield'` ·
`'spear_shield'` · `'dual_slash'` · `'great_sword'` · `'war_hammer'` · `'long_staff'` · `'poleaxe'` ·
`'lance'` · `'bow'` · `'crossbow'` · `'arbalest'` · `'thrown_pierce'` … 갈래가 갈리는 종류는 속성이 키에
들어간다. 모르는 키는 지금처럼 맨손.

`powOfWeapon` 은 쌍수에서 **두 무기의 평균**이다 — 합이면 쌍수가 무조건 이긴다.

### 4.3 전투 — `WeaponProfile` 이 조금 자란다

| 필드 | 뜻 | 쓰는 종류 |
|---|---|---|
| `strikes` (기본 1) | 한 행동에 굴리는 횟수 | 쌍수 2 |
| `coatingSlots` (기본 1) | 도포 칸 | 쌍수 2 |
| `evasionBonus` · `initiativeBonus` | 상시 | 한손 · 쌍수 · 장봉 · 망치 · 석궁 · 아르발레스트 |
| `braceBonus` (기본 45/12) | 버팀 값 | 창과 방패 60/20 |
| `counters` | 버틴 채 맞으면 되돌려침 | 창과 방패 |
| `chargeAlwaysPushes` | 돌격 명중 = 밀기 | 전투 망치 |
| `momentum` | 기세 최대 단 | 대검 3 |
| `transformBonus` | 변형 강타 % | 장병기 30 |
| `setBonus` | 거치 % | 아르발레스트 25 |
| `coatingOnly` | 피해 없이 도포만 | 블로우 파이프 |

`Combatant` 에 상태 셋 — `momentum`(기세), `set`(거치), `lastAttackWasReach`(변형 강타용). 전부 라운드
경계에서 규칙대로 정리된다. `coating` 은 `List<WeaponCoating>` 이 된다(칸 수만큼).

방식 선택(`chooseAttack`)·사거리 벌점·대상 가중·밀림은 **그대로**다. 새 종류는 전부 그 위에 얹힌다.

### 4.4 문구 — `hd_battle_text`

종류 이름 13 · 고유 동작 문장(받아쳤다 · 기세가 오른다 · 거치했다 · 도끼로 바꿔 벴다) · 상태 배지(기세 ★★★ ·
거치 ▲ · 도포 둘). 콘솔과 Flutter 가 같은 것을 쓴다.

### 4.5 아이템 — 원작 31종 이식

카탈로그를 C++ 10종에서 **Unity 31종**으로 넓힌다(`WEAPON_LIST`, `hands` · `shape` 를 붙여서). 이름·값은
원작 그대로고 판단은 손 구성 둘뿐이다 — 이식이다. BP-42 §7 의 20종 카탈로그(단검·단창·작은 도끼·강철 검)는
그 안에 그대로 들어간다.

## 5. 지키는 것 — 검증

- **거리 0 을 덮지 않는 종류가 없다** — `purity_test` 에 한 줄: 모든 profile 의 방식 중 `minReach == 0` 이 하나는 있다.
- **쌍수는 한 행동에 한 번만 밀어낸다** — fixture.
- **기세는 피격에 0 이 되고 버팀 중에는 지켜진다** — fixture.
- **거치는 열이 바뀌면 풀린다** — 밀림 fixture 에 아르발레스트 하나.
- **`weaponKindOf` 는 §2 표와 일치한다** — 조합 전수 테스트 (갈래 5 × 보조 4).
- **한손 경장의 회피 +4 는 `ac 5` 방패의 +12 보다 작다** — 상수 테스트. 방패를 버리는 선택이어야 한다.

## 6. 직업과의 관계 ([BP-44 §7](44_bestiary.md))

| 직업 | 어울리는 종류 | 표에서 |
|---|---|---|
| 기사 | 검과 방패 · 창과 방패 | 방패 20~60 |
| 검사 | 대검 · 한손 · 쌍수 | 베는 40~100 |
| 사냥꾼 | 활 · 석궁 · 아르발레스트 · 투척 | 쏘는 40~100 — **"사격 preset 없음" 이 여기서 닫힌다** |
| 전투승 | 장봉 · 한손(너클) | 타격 40~100 |
| 전사 | 창과 방패 · 전투 망치 | 방패 20~70 · 베는 25 |
| 암살자 | 쌍수 · 투척(블로우 파이프) | 베는·쏘는·특수 — **도포 둘이 이 직업의 것** |
| 에스퍼 · 초능력자 | 한손 · 장봉 | 무기 0~40 — 가볍게 |

직업이 종류를 **막지는 않는다**(원작도 막지 않았다 — 기술 최소치만 있다). 어울림은 preset 목록과 상점 배치가
말한다.
