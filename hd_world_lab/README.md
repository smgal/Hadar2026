# hd_world 실험실 — 왜 서버인가

`hd_battle_console` 이 전투에 한 일을 장비에 하는 곳이다. 다만 **터미널이 아니다.**

## 왜 콘솔이 아닌가

전투는 「1) 공격 2) 기술 …」 처럼 **한 번에 한 물음**이라 터미널이 잘 맞았다.
장비는 그렇지 않다.

- 부위가 여덟이고 **동시에 보여야** 한다 — 왼손을 채우면 오른손이 잠긴다
- 고칠 때마다 **최종 수치가 다시 계산**되고, 그 차이를 보려고 만지는 것이다
- 후보가 스무 개를 넘는다. 번호를 외워 누르는 일이 아니다

그래서 화면 하나와 API 하나를 둔다. **모델이 이미 명령과 사실로 말하기 때문에**
둘이 같은 문을 쓴다 — 서버는 규칙을 하나도 갖지 않는다.

## 세 갈래로 같은 모델을 만진다

| 누가 | 어떻게 |
|---|---|
| 사람 | `GET /` 의 장비 화면. 마우스 |
| 스크립트 | `POST /api/command`. JSON |
| 에이전트 | `GET /api/guide` 를 먼저 읽고 같은 명령을 쓴다 |

화면은 **한국어를 스스로 갖지 않는다.** `GET /api/text` 를 한 번 받아 전부
거기서 찾는다. 그래서 이름이 화면과 터미널에서 갈릴 수 없다 —
`hd_battle_text` 가 전투에 대해 지키는 것과 같은 규칙이다.

## 무엇이 안에 없나

- 규칙 — 전부 `packages/hd_world` 다
- 한국어 — 전부 `packages/hd_world_text` 다
- 저장 — 메모리 안의 파티 하나다. `POST /api/reset` 이 처음으로 돌린다
- 인증 — 없다. 로컬 개발 서버다

실행 방법은 [RUN.md](RUN.md).
