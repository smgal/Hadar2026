## 준비 (한 번만)

```bash
cd hd_battle_console
dart pub get
```

**Flutter SDK 는 필요 없다.** 순수 Dart 라 `dart` 만 있으면 된다.

## 0. 터미널이 힘들면 — **전투 실험실**

같은 fixture 를 Flutter 화면으로 연다. 마우스로 누르고, **한 수 물릴 수 있다.**

```bash
cd ../hadar2026_app
flutter run -t lib/battle_lab_main.dart             # 데스크톱
flutter run -d chrome -t lib/battle_lab_main.dart   # 브라우저
```

fixture 를 고치면 `dart run tool/make_fixtures.dart` 를 돌린다 — 앱 쪽 사본까지
함께 만들어진다. 아래는 터미널에서 굴리는 방법이다.

## 1. 직접 플레이

```bash
dart run bin/battle.dart fixtures/rules/orc_x3.json
```

턴마다 메뉴가 나온다. **숫자를 입력하고 Enter.**

```
슴갈의 전투 모드 ===>
  1) 한 명의 적을 단도로 공격
  2) 한 명의 적에게 마법 공격
  3) 모든 적에게 마법 공격
  4) 적에게 특수 마법 공격
  5) 일행을 치료
  6) 적에게 초능력 사용
  7) 앞에 서서 버팀 (다음 공격을 막을 확률이 크게 오름)
  8) 일행에게 무조건 공격 할 것을 지시
  9) 일행 전체가 앞으로 (이 턴은 공격하지 않음)
  0) 취소
> 1                       ← 여기에 입력

공격할 적을 선택하십시오 ===>
  1) Orc  (HP 8)
  2) Orc  (HP 8)
  0) 취소
> 1
```

| | |
|---|---|
| **0** | 행동 메뉴에서는 **이 턴을 넘긴다**, 하위 물음(대상·기술·물건)에서는 **뒤로** — 턴을 잃지 않는다 |
| **묻는 순서** | 리더 → 1열 → 2열 → 3열. 상태 표도 같은 순서다. 적이 하나면 대상을 묻지 않는다 |
| **버팀** | 앞으로 나서서 방패를 세운다. 앞에 서면 **실제로 더 맞으니** 그게 값이다 |
| **일행 전체가 앞으로** | 슬롯 0 만 낼 수 있고 **그 턴은 공격하지 않는다**. 간격이 0 이면 메뉴에 안 나온다 |
| **파고들며 공격** | 돌격 가능한 무기(기병창·대검)를 들고 뒤에 서 있을 때만 나온다 |
| **기술** | 마법과 초능력이 **한 목록**이다. 글자가 범위를 말한다 — 🎯 한 명 · 💥 전체 · ☠ 저주 · 💚 아군 · 💞 일행 · 🌀 내 무기 · 🔮 초능력(ESP). 못 쓰는 것은 어둡게 남는다. **8줄을 넘으면** 먼저 묶음(≤7)을 고르고 그 안에서 고른다 |
| **도망** | **리더**(의식 있는 가장 낮은 슬롯)가 낸다. 일행 전체가 한 번 굴리고, **간격이 클수록 쉽다**(+15/칸). 실패하면 그 턴을 다 잃는다 |
| **지시** | 리더 전용 하위 메뉴 — 자동 전투 · 대열 전진 · 후퇴 |
| **물건** | 회복약 💚 · 기력의 약 💙 · 병 🟣⚡🔥 — **바르거나(3턴) 던진다(지금 한 번)**, 고른 뒤 묻는다 · 결정 🎯💥 |
| **Ctrl+C** | 나가기 |

## 2. 어떤 fixture 가 있는지

```bash
dart run bin/battle.dart
```

**두 벌로 나뉘어 있다.**

| 폴더 | 목적 | 파티 |
|---|---|---|
| `fixtures/original/` | 원작 조우를 그대로 | **원작 시작 파티(2인)** |
| `fixtures/rules/` | 규칙 하나씩 시연 | **5인 기본 파티** |

실제 게임은 5인 + 소환수인데 예전에는 17개 중 14개가 2인이었다. 그 차이가 크다 —
라운드가 절반이 되고, **적의 특수 능력이 2인에서는 한 번도 발동하지 않는다.**

### 위치 전투를 보려면 이 넷

| fixture | 무엇을 보는가 |
|---|---|
| `rules/reach.json` | **졸개 뒤의 보스** — 사거리가 모자라면 앞의 졸개가 대신 맞는다 |
| `rules/knockback.json` | **타격이 줄을 민다** — 철퇴로 해골을 밀어내면 뒤가 드러난다 |
| `rules/formation.json` | **대열 전진 · 돌격 · 전진 방어** — 명령이 맞받는 것도 보인다 |
| `rules/preset.json` | **겁쟁이는 도망간다** — 그리고 자동은 눈이 멀었다 |

### 나머지

| fixture | 무엇을 보는가 |
|---|---|
| `original/town1_pair.json` | 원작 마을 조우 (Giant + Wolf) |
| `original/devil_hunter_x7.json` | 원작 조우 — 시작 파티로는 전멸한다 |
| `rules/orc_x3.json` | 기본 승리 |
| `rules/wipe.json` · `rules/escape.json` | 종료 코드 2(전멸) · 0(도주 — 리더의 파티 행동) |
| `rules/escape_gap.json` | **간격이 도망 확률을 만든다** — 물러선 뒤 달아나기 |
| `rules/coating.json` | **무기에 바르기** — 독병과 마법 13, 두 길이 한 곳으로 |
| `rules/initiative.json` | 행동 순서가 민첩을 읽는다 |
| `rules/finishing_blow.json` | 쓰러진 적을 다시 내리친다 |
| `rules/party_poison.json` | 파티 독으로 죽는 경로 |
| `rules/heal.json` · `rules/cure_full.json` | 치료 4갈래와 복합 치료 |
| `rules/magic.json` · `rules/debuff.json` | 전체 공격 마법 · 특수 마법 |
| `rules/items.json` | 전투 중 물건 |
| `rules/armour.json` | 부위별 감쇠와 방패 |
| `rules/affinity.json` | 마법 속성 상성 |
| `rules/enemy_ai.json` · `rules/enemy_special.json` | 적 AI 자가 치료 · 특수 능력 |

## 3. 입력 없이 빨리 보기

기록된 명령 열을 재생한다. **몇 번 돌려도 같은 출력**이 나온다.

```bash
dart run bin/battle.dart fixtures/rules/heal.json --replay
dart run bin/battle.dart fixtures/original/town1_pair.json --replay --no-status
```

`--no-status` 는 턴마다 나오는 상태 표를 생략한다. 로그만 훑어볼 때 편하다.

## 4. 다른 난수로 보기

같은 상황을 다른 운으로 보고 싶을 때. **대화형과 같이 쓴다.**

```bash
dart run bin/battle.dart fixtures/rules/orc_x3.json --seed=1234
```

> `--seed` 와 `--replay` 를 같이 쓰면 기록된 명령 열이 어긋나 중간에 멈출 수 있다
> (운이 맞으면 그냥 끝나기도 한다). 멈추면 안내에 나오는 `--record` 명령을 그대로
> 실행하면 된다.

## 5. 자동 플레이 (방침만 정하고 맡기기)

```bash
dart run bin/battle.dart fixtures/rules/magic.json --record=magic-all
```

방침: `attack` · `auto` · `escape` · `skill` · `magic` · `magic-all` · `special` ·
`coat` · `heal` · `esp` · `item` · `throw` · `charge` · `brace` · `advance` · `fallback` · `skip`

B6 이후 마법은 한 목록이라 `magic`·`magic-all`·`special`·`coat`·`heal`·`esp` 는
**그 목록에서 무엇을 고를지**(범위 필터)다. `auto`·`advance`·`fallback` 은 지시
메뉴를 거친다.

**슬롯마다 다르게** 줄 수 있다. 5인이 다 치료하면 아무도 적을 못 잡으니 필요하다.

```
attack,4=heal:21        슬롯 4 만 치료. 나머지는 공격
attack@3                `@` 뒤는 노릴 적 번호 — 뒷열의 보스를 일부러 노릴 때
magic:2,2=attack,4=heal `:` 뒤는 고를 마법 id
```

## 새 상황을 만들고 싶을 때

`tool/make_fixtures.dart` 에 fixture 정의가 모여 있다. 적 구성·HP·대열을 바꾸고

```bash
dart run tool/make_fixtures.dart        # 20개를 만들고 명령 열까지 기록한다
```

**한 줄이면 전부 다시 만들어진다.** 방침이 fixture 안에 `record` 로 들어 있어서다.
규칙을 바꿔 난수 순서가 달라지면 이 한 줄로 되살린다.

적 키 목록은 75종이다 — `packages/hd_battle/lib/src/data/enemy_table.dart` 의
`key:` 값들 (`orc` · `troll` · `giant` · `devil_hunter` · `neo_necromancer` …).
무기 키는 `packages/hd_battle/lib/src/rules/weapon.dart` 의 `weaponTable`.

## 출력 읽는 법

### 줄 앞의 `·` 는 원작에 없던 줄이다

독 피해, 골드 획득, 턴 구분. 원작이 조용히 지나가던 것이라 여기서는 보이게 했다.
표시가 없는 줄은 원작과 같은 문장이다.

### 색이 상태를 알려 준다

터미널에 바로 띄우면 색이 켜진다. 파일이나 파이프로 보내면 저절로 꺼진다.

| | |
|---|---|
| `--color` | 파이프로 보낼 때도 색을 켠다 |
| `--no-color` | 끈다. 환경 변수 `NO_COLOR` 도 같은 일을 한다 |

**색은 우리가 고른 것이 아니라 원작에 있던 것이다.** 원작의 전투 메시지는 전부
`writeConsole(색번호, ...)` 로 나갔고 그 첫 인자가 색이었다. 그 호출들을 훑어서
그대로 옮겼다(근거는 `blueprint/_meta/GROUND_TRUTH.md` 부록 V).

로그 줄:

| 색 | 뜻 |
|---|---|
| 밝은 빨강 | 일행이 움직인 줄 |
| 밝은 자홍 | 적이 움직인 줄 |
| 밝은 회색 | 빗나감·저지·막힘·실패 |
| 자홍 | 일행이 입은 피해 (수치만 더 밝다) |
| 빨강 | 상태가 나빠짐 — 중독·의식불명·사망·능력 저하 |
| 하양 | 치료 성공·금화 |
| 노랑 | 경험치 |
| 밝은 청록 | 도주 성공·적 영입 |
| 밝은 초록 | 적이 겁먹고 달아남 |
| 진한 회색 | 턴 구분 같은 진행 표시 (원작에 없던 줄) |

**이름 색이 곧 상태다.** 이것도 원작 규칙이다 — 원작 화면은 320x240 이라 상태를
글자로 적을 자리가 없어서 이름 색으로만 알렸다.

- **적**: 남은 체력 — 밝은 초록(300 초과) → 초록 → 노랑 → 갈색 → 빨강 →
  밝은 빨강(20 이하) → 진한 회색(쓰러짐). **비율이 아니라 절대 체력**이라
  덩치 큰 적은 반쯤 깎여도 초록이다. 원작이 적의 최대 체력을 안 보여줬으니 그렇다.
- **일행**: 하양(멀쩡) · 밝은 자홍(중독) · 밝은 회색(의식 불명) · 진한 회색(사망).

메뉴는 머리글이 밝은 빨강, 항목이 밝은 회색이다. 이것도 원작 메뉴 색 그대로다.

### 끝의 「전투 정산 결과」가 RPG 로 넘어갈 값 전부다

```
=== 전투 정산 결과 (RPG 로 넘어가는 값) ===
  종료 코드 : 승리 (cm2 Battle::Result() = 1)
  획득 골드 : 15
  소비 아이템: 없음 (B2-06)
  전투 밖 효과 요청: 없음 (B2-01)
  파티 슬롯별:
    슬롯 0 슴갈  HP 150  SP 100  ESP 100  독 0  의식불명 0  사망 0  획득 경험치 21
  (레벨업은 RPG 가 판정한다 — B3-05)
```

이것이 나중에 RPG 쪽 파티에 반영된다(B3). 지금은 화면에 찍고 끝난다.

| 적 특수 능력 | 없음 | 독·기절·즉사. **파티 4명 이상**일 때만 나오고 **행운이 막는다** |
| 초자연 능력 | 읽는 곳 0 | 한 턴에 **두 번 행동**하고, **적을 소환**하고 **파티원을 끌어간다** |
| 행동 순서 | 파티 슬롯 순 → 적 순 | 양쪽이 한 줄에 섞이고 **민첩**으로 정렬 |
| 물건 | 없음 | 약품·결정. **마법 지수를 쓰지 않는다** — 마법 없는 캐릭터의 할 일 |
| 방어 | `ac` 하나 | **부위별 합산 + 방패는 한 대를 통째로 막는 확률** |
| 속성 | 없음 | 약점 ×2 / 저항 ÷2. 얇게 — 마법 18종 중 9종만 속성을 갖는다 |
| 죽은 파티원 HP | 음수로 남음 | 0 으로 정리 |

## B5 로 달라진 것 — **전투에 위치가 생겼다** (2026-09-05)

**B5 는 2026-09-05 에 완료됐다** — 11개 항목, 규격 **v2** 확정.
근간은 그대로 드래곤 퀘스트다: 라운드 시작에 전원 명령 → 일괄 해결, 자유 이동 없음.

### 상태는 정수 두 종류다

```
각자의 열 rank 1(앞)~3(뒤)  +  양측 공통의 간격 gap 0~2
거리 = gap + (내 열 - 1) + (상대 열 - 1)
```

좌표가 아니라 격자 게임이 되지 않는다. **포기한 것**: 측면 우회 · 한 열 안의 개별
위치 · 특정 적만 골라 밀어내기.

| 무엇 | 전 | 후 |
|---|---|---|
| 적의 공격 대상 | **균등 난수** — 대열이 전투에 아무 영향이 없었다 | **열 가중.** 앞열이 뒷열의 **3배**를 맞는다 |
| 무기 | `powOfWeapon` 정수 하나 — 10종이 사다리 하나 | **방식 1~2개** × (속성 · 사거리 하한~상한 · 위력). 창은 자루로도 친다 |
| 물리 저항 | 확률 판정 (절반 넘는 적에게 아무 일도 안 함) | **종족 면역**만. Sprite · Stheno · Euryale 처럼 |
| 피해 편차 | 아군 0.51~1.0, 적 0.1~1.0 — 모양이 달랐다 | **회피 배율 하나**로 통일. `agility` 가 드디어 일한다 |
| 방패 | 별도 굴림 | 회피 배율에 합쳐졌다 — 막기는 배율 0 이다 |
| 물리 속성 | 없음 | **베기/찌르기/타격.** 살은 베기에 약하고 언데드는 타격에 약하다 |
| 이동 | 없음 | 대열 전진(리더의 턴) · 돌격 · 전진 방어 |
| 밀어내기 | 없음 | **타격으로 약점을 찌르면 한 열.** 벽에 몰리면 추가 피해 |
| 상시 지시 | 자동 전투 켜기/끄기 | **preset 6종.** 겁쟁이는 도망가고, 자동은 **눈이 멀었다** |
| 전투 중 합류 | 판에서 지우고 나중에 RPG 가 자리 찾음 | **슬롯에 앉아 싸운다.** 정원이 차면 메뉴에서 빠진다 |

```
앞을 막아선 Orc이 슴갈의 공격을 ArchiMage 대신 받아냈다

```

### 위치는 화면에 다 나온다 — 계산은 할 필요 없다

턴마다 나오는 상태 표 맨 위가 **대열 한 줄**이다.

```
  [3] 술사 치유사  [2] 유리  [1] 슴갈 방패병  ←───→ 간격 1  [1] Orc Orc  [3] ArchiMage

  적
    1. Orc                 1열  HP     8   의식 있음
    4. ArchiMage           3열  HP   870   의식 있음

  일행
   0. 슴갈          1열  HP   150/ 150  ...  의식 있음  닿음 1,2,3
   3. 술사          3열  HP    90/  90  ...  의식 있음  닿는 적 없음
```

**맨 오른쪽 「닿음 1,2,3」이 핵심이다** — 지금 이 사람의 무기가 몇 번 적에게 닿는지.
화살표 길이가 간격이라 숫자보다 먼저 눈에 들어온다.

대상을 고를 때는 더 자세히 나온다.

```
공격할 적을 선택하십시오 ===>
  1) Orc               1열  거리 1  닿음 · 찌르기  HP 8
  4) ArchiMage         3열  거리 3  2칸 부족 · 명중 -14 · 앞열이 대신 55%  HP 870
```

**안 닿아도 목록에서 빼지 않는다.** 빈틈을 노려 보스를 바로 치는 도박이 남아야 하고,
무엇을 무는지 알고 거는 것과 모르고 거는 것은 다르다.

행동 메뉴 머리글에도 자기 정보가 붙는다 —
`슴갈의 전투 모드 1열 · 찌르기 0~1 · 간격 1 ===>`.

### 규칙 하나만 기억하면 된다

> **사거리 밖은 벌점이지 무효가 아니다.**

명중이 깎이고 앞의 누군가가 대신 맞을 뿐, **턴이 사라지는 경우는 없다.**
위치를 움직이는 것이 넷이고(대열·돌격·넉백·회피 후퇴) 그중 둘은 명령을 낼 때
예측할 수 없다. 그래서 결과가 **나빠질 뿐 없어지면 안 된다.**

## 밸런스는 손대지 않았다

원작 수식을 옮긴 결과라 이런 것이 남아 있다 (`GROUND_TRUTH` 부록 U · X-4):

- **Black Knight 의 최대 피해 943** — 파티 최대 체력의 몇 배다.
  사슬이 아니라 **데이터** 문제다 (`힘 × 레벨` = 945)
- **마법이 물리를 압도한다** — 마법 레벨 20 의 6번 마법 1440 대 무기 최대 18

B5-05 가 물리 기본 피해를 2배로 올려 평균 4.4 → **10.3** 이 됐지만 마법 쪽은
건드리지 않았다. 둘 다 고치려면 원작에서 더 멀어져야 한다 — RPG 에 붙여서 실제로
플레이해 본 뒤 판단하기로 했다([7차 판정](../issues/DECISION-LOG.md)).

그리고 **초능력 41·42·44 는 전투 중 아무것도 하지 않는 것이 정상**이다 — 원작이 그랬다.
