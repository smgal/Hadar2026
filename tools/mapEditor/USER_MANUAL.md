# 사용자 매뉴얼 — Hadar 맵 에디터 (브라우저 UI)

이 문서는 브라우저에서 여는 맵 에디터 화면을 사람이 직접 쓰는 방법을 설명한다. AI/스크립트로 제어하는 방법은 [API_MANUAL.md](API_MANUAL.md)를 참고.

## 1. 시작하기

```bash
cd tools/mapEditor
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:5310` 을 연다. 기본으로 `hadar2026_app/assets`를 대상으로 하며, 다른 위치를 열려면:

```bash
HADAR_ASSETS=/path/to/assets pnpm dev
```

URL에 파라미터를 붙이면 시작 상태를 지정할 수 있다: `http://localhost:5310/?map=TOWN1.json&night=1&light=1`

## 2. 화면 구성

```
┌─────────────────────────────── 툴바 ───────────────────────────────┐
│ [맵 선택▾] [저장] ● | [↩][↪] | [붓][사각형][채우기][스포이드][지우개] │
│ | [−]100%[+] | [격자][통행] | [야간][달빛][광원] [시야 슬라이더]   │
├───────────────────────────────────┬─────────────────────────────────┤
│                                    │  맵 정보 (이름/크기/리사이즈)  │
│                                    ├─────────────────────────────────┤
│                                    │  레이어 목록 (👁 눈 아이콘)     │
│           캔버스 (맵)             ├─────────────────────────────────┤
│                                    │  팔레트 (레이어별로 바뀜)       │
│                                    ├─────────────────────────────────┤
│                                    │  이벤트 패널 (이벤트 레이어일 때)│
├────────────────────────────────────┴─────────────────────────────────┤
│ (x,y)  L0:.. L1:.. ...   액션: MOVE | 이벤트: ..     [상태 메시지]   │
└─────────────────────────────────────────────────────────────────────┘
```

- **툴바**(위): 맵 선택, 저장, 실행취소/다시실행, 편집 도구, 확대/축소, 격자·통행 표시, 야간/조명 옵션
- **캔버스**(가운데): 실제 맵. 마우스로 칠하고 확인
- **사이드바**(오른쪽): 맵 정보 · 레이어 목록 · 팔레트 · (이벤트 레이어일 때) 이벤트 패널
- **상태바**(아래): 커서 위치, 각 레이어 값, 통행 판정, 힌트 메시지

## 3. 맵 열기 / 저장 / 되돌리기

### 3.1 맵 열기

툴바 왼쪽 드롭다운에서 맵을 고른다. 목록 옆 괄호 안 이름은 `MapInfos.json`에 등록된 논리 이름(게임이 인식하는 이름)이다. 저장하지 않은 변경이 있으면 전환 전에 확인창이 뜬다.

에디터는 **마지막으로 연 맵을 기억**한다(브라우저에 저장) — 새로고침하거나 서버를 재시작해도 같은 맵으로 돌아온다.

### 3.2 저장

`저장` 버튼 또는 `Ctrl+S`. 저장 안 된 변경이 있으면 저장 버튼 옆에 주황색 점(●)이 뜬다.

**충돌**: 이 에디터는 AI API로도 같은 파일을 수정할 수 있다. 내가 편집하는 동안 AI가 같은 파일을 먼저 저장했다면, 내가 저장할 때 "파일이 외부에서 변경됨" 확인창이 뜬다 — **확인**하면 AI가 만든 변경을 버리고 내 화면 내용으로 덮어쓰고, **취소**하면 저장하지 않는다(내 편집은 브라우저에 남아있음). 지금은 자동 병합 기능이 없으므로 겹치는 부분이 있으면 둘 중 하나가 사라진다는 점을 유의.

내가 편집 중이 아닐 때 AI가 파일을 바꾸면, 2초 안에 자동으로 화면이 갱신된다(화면 위치는 유지). 붓질·사각형 드래그 중이거나 사이드바 입력칸(이벤트 인스펙터, 표시 이름, 크기)에 커서가 있으면 자동 갱신을 미루므로, 작업 중이던 내용이 갑자기 날아가지는 않는다.

### 3.3 되돌리기 / 다시 실행

`Ctrl+Z` / `Ctrl+Shift+Z` (또는 `Ctrl+Y`). 붓질 한 번(마우스를 눌렀다 뗄 때까지)이 되돌리기 한 단계다. 최대 200단계까지 기억한다.

**주의**: 이건 저장 전 편집 취소용이다. 이미 저장한 내용을 되돌리려면 `git checkout -- hadar2026_app/assets/maps/파일.json` 처럼 git으로 되돌려야 한다(저장소가 git 관리라는 전제).

## 4. 레이어와 팔레트

오른쪽 사이드바의 "레이어" 목록에서 클릭(또는 숫자키 `1`~`7`)으로 활성 레이어를 바꾼다. 👁 아이콘을 누르면 해당 레이어를 화면에서 껐다 켰다 할 수 있다(편집 대상과는 별개).

| 번호 | 레이어 | 의미 | 팔레트 |
|---|---|---|---|
| 1 | L0 지면 (A5) | 바닥 타일 | Lore_A5.png 128타일 |
| 2 | L1 지면2 | 게임에서 안 쓰는 레이어 — 원본 보존용, 편집할 일 거의 없음 | Lore_A5.png |
| 3 | L2 오브젝트 하단 (B) | 장식 오브젝트 | Lore_B.png 256타일 |
| 4 | L3 오브젝트 상단 (B) | 오브젝트 — **통행 판정에 영향** | Lore_B.png |
| 5 | L4 빛/그림자 | 야간 밝기 (0=항상 밝음 ~ 15=완전 암전) | 16종 비트 패턴 |
| 6 | L5 지역 ID | 스크립트가 읽는 지역 번호 | 숫자 입력 |
| 7 | 이벤트 | 대화·표지판·이동 등 | 이벤트 패널 |

팔레트에서 타일을 클릭하면 그 타일이 "선택된 값"이 되고, 캔버스에 칠하는 도구들이 그 값을 사용한다. L2/L3(오브젝트)는 팔레트 맨 아래 **지우기(0)** 칩으로 오브젝트 제거를 선택할 수 있다.

## 5. 편집 도구

| 도구 | 아이콘 | 단축키 | 사용법 |
|---|---|---|---|
| 붓 | ✏️ | `B` | 클릭 또는 드래그로 칠하기 |
| 사각형 | ▭ | `R` | 드래그로 영역 지정 → 뗄 때 채워짐. **우클릭 드래그면 그 영역을 지움** |
| 채우기 | 🪣 | `F` | 클릭한 지점과 같은 값으로 이어진 영역을 전부 채움 |
| 스포이드 | 💉 | `I` (또는 Alt+클릭) | 클릭한 타일의 값을 팔레트 선택으로 가져옴 |
| 지우개 | 🧽 | `X` (또는 우클릭) | 0으로 지움. 어느 도구를 쓰든 우클릭은 지우기 동작 |

한 조작이 진행 중일 때(붓질·사각형 드래그·화면 이동) 다른 버튼을 눌러도 무시된다 — 사각형을 그리다 실수로 우클릭해서 영역이 날아가는 일은 없다.

기타 조작:

- **화면 이동**: Space를 누른 채 드래그, 또는 마우스 휠 클릭 드래그
- **확대/축소**: `Ctrl`+휠, 또는 툴바의 `−`/`+`
- **격자 표시**: `G` 또는 체크박스
- **통행 오버레이**: "통행" 체크박스 — 벽(빨강)·물(파랑)·표지판(시안)·대화(마젠타)·입구(노랑) 등 게임의 실제 통행 규칙을 색으로 표시. L3 오브젝트나 이벤트가 그 위에 있으면 지면 값보다 우선한다.

## 6. 야간 / 조명 미리보기

툴바의 "야간" 체크박스를 켜면 게임과 동일한 공식으로 그림자 레이어(L4)를 반영해 어둡게 렌더링한다.

- **달빛**: 끄면 완전 암전 구역이 더 어둡게(두 겹) 표시됨 — 게임에서 달빛 없는 날 밤과 동일
- **광원**: 켜면 캔버스에 플레이어 위치(노란 원)와 시야 반경이 표시된다. `Ctrl+클릭`으로 위치를 옮기고, 시야 슬라이더(1~4)로 반경을 조절해 실제 플레이 시 어디까지 보이는지 확인할 수 있다

빛 레이어(L4)를 직접 칠할 때 기준: **실내·광원 근처는 0(항상 밝음)**, **야외·동굴은 15(완전 암전)**, 그 사이 값은 사분면 비트(1=좌상 2=우상 4=좌하 8=우하)로 부분 그림자를 표현한다.

## 7. 이벤트 다루기

레이어를 "이벤트"로 전환(숫자키 `7`)하면 팔레트 자리에 이벤트 패널이 뜬다.

- **새 이벤트**: 타입(TALK/SIGN/EVENT/ENTER/NPC) 선택 후 "새 이벤트" — 이름은 자동으로 `TALK001`처럼 매겨진다. 생성 위치는 마지막 마우스 위치 근처
- **선택/이동**: 캔버스에서 이벤트를 클릭하면 선택되고 인스펙터가 뜬다. 선택된 상태에서 빈 타일을 클릭하면 그 위치로 이동
- **인스펙터 필드**:
  - 이름 — 접두사(TALK/SIGN/EVENT/ENTER/NPC)가 게임의 동작 타입을 결정하므로 함부로 안 바꾸는 게 안전
  - 메모 — 편집자용, 게임에 영향 없음
  - 위치 — 직접 좌표 입력 가능
  - 대사 — 한 줄씩 입력, 게임에서 순서대로 출력됨
  - hadarEvent 확장 kind — `warp`(맵 이동), `oneshot`(1회성), `talk`/`sign`(대사만) 중 선택, payload는 JSON으로 직접 입력(예: `{"map":"TOWN1","x":10,"y":20}`)
  - **적용** 버튼을 눌러야 반영됨(입력 중엔 저장 안 됨)
  - **삭제** — 확인 후 즉시 삭제

## 8. 맵 정보 / 크기 조정

사이드바 맨 위 "맵 정보"에서:

- **표시 이름**: 게임에 보이는 맵 이름
- **크기 리사이즈**: 가로×세로 입력 후 "리사이즈" — **좌상단 기준**으로 내용을 유지하며, 잘려나가는 영역의 타일/이벤트는 사라지거나(축소 시) 안쪽으로 당겨진다(이벤트가 새 범위 밖이면 클램프). 확인창이 뜨니 신중히

## 9. 단축키 모음

| 키 | 동작 |
|---|---|
| `B` / `R` / `F` / `I` / `X` | 붓 / 사각형 / 채우기 / 스포이드 / 지우개 |
| `1`~`7` | 레이어 전환 (7 = 이벤트) |

| `Ctrl`+휠 | 확대/축소 |
| Space+드래그 / 휠클릭 드래그 | 화면 이동 |

## 10. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 타일 그림이 안 보이고 회색/빈 화면 | `Lore_A5.png`/`Lore_B.png` 로드 실패. `HADAR_ASSETS` 경로가 맞는지, `assets/images/` 안에 두 파일이 있는지 확인 |
| 맵 드롭다운이 비어있음 | 대상 `assets/maps/` 디렉토리가 없거나 비어있음. 서버 콘솔 로그와 `HADAR_ASSETS` 확인 |
| 저장이 안 되고 "외부에서 변경됨" 창만 뜸 | 다른 곳(AI API 등)에서 같은 파일을 먼저 저장함. 3.2절 참고 — 지금은 자동 병합이 없으니 어느 쪽을 남길지 직접 선택 |
| 새로고침했더니 다른 맵이 열림 | 브라우저의 localStorage가 초기화됐거나(시크릿 모드 등) URL에 `?map=` 파라미터가 있으면 그게 우선함 |
| 리사이즈했더니 이벤트가 이상한 곳에 있음 | 축소 시 범위 밖 이벤트는 새 경계 안쪽으로 당겨짐(클램프) — 의도된 동작. 필요하면 실행취소 |
| 대사를 수정했는데 이벤트가 이상하게 동작함 | 원래 그 이벤트에 조건분기 등 복잡한 커맨드가 있었다면, 대사 수정 시 페이지 전체가 표준형으로 재구성되어 그 로직이 사라진다. [DEVLOG.md](DEVLOG.md) 4.2절 참고 — 이런 이벤트는 원본 JSON을 직접 편집할 것 |
