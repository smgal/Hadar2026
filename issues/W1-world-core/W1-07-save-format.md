# W1-07 세이브 — 부위 여덟을 싣는 포맷

- **상태**: DONE (2026-09-09)
- **구간**: W1 ([_README](_README.md))
- **규모**: M
- **선행**: [W1-02](W1-02-slots-and-items.md)

## 문제

옛 세이브는 부위 여섯을 `(kind, index)` 정수 쌍으로 싣는다. 새 모델은 **문자열 ref**
(`weapon.long_sword`)를 쓴다. 정체성을 바꾼 것이 판단이다 — 표 위치로 물건을 가리키면
줄을 끼울 때 뒤가 전부 이름을 바꾼다.

**지킬 세이브 파일은 없다**(부록 Z, 파일 0개, 릴리스 없음). 그래도 부위 번호 0~5 는
옮기지 않았으므로 다리를 놓을 수는 있다.

## 무엇을 할 것인가

- `World` → JSON, JSON → `World`. 이미 있는 `toJson` 은 **읽기 전용 view** 다.
  세이브는 파생값을 싣지 않는다 — 인물 · 착용 ref · 가방 · 지시만.
- `legacyIndex` 로 옛 정수를 ref 로 옮기는 표. 카탈로그가 이미 그 칸을 갖고 있다.
- **모르는 ref 를 만나면 무엇을 하는가** 를 정한다. 조용히 맨손으로 접으면 부록 F-1 과
  같은 침묵 실패다. 후보: 그 칸을 비우고 **무엇을 잃었는지 이벤트로 알린다.**

## 무엇을 했나

`packages/hd_world/lib/src/contract/persistence.dart`.

**파생값을 하나도 싣지 않는다** — 무기 종류·최종 수치·통행 능력·시야가 없다.
싣으면 세이브가 규칙과 어긋날 수 있고, 그때 옛 답이 이긴다.

**모르는 참조는 칸을 비우고 알린다.** `LoadResult.issues` 로 돌아오고
세이브 관리자가 찍는다 — 조용히 맨손이 되면 부록 F-1 과 같은 침묵 실패다.

잘린 세이브도 **던지지 않는다.** 읽은 만큼 살리고 못 읽은 것만 이슈로 남긴다 —
파티 하나가 깨졌다고 나머지를 잃는 것이 더 나쁘다.

옛 v1·v2 페이로드는 `world` 키가 없으므로 **새 파티로 시작하고 그것을 알린다.**
지킬 세이브 파일이 0개라(부록 Z) 정수 이식표는 만들지 않았다 —
`hd_world_legacy` 가 필요해지면 그때 쓴다.
