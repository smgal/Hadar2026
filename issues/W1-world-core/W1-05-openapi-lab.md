# W1-05 OpenAPI 표면과 마우스 화면

- **상태**: DONE (2026-09-08)
- **구간**: W1 ([_README](_README.md))
- **규모**: L
- **선행**: [W1-03](W1-03-derived-values.md)

## 문제

**터미널로는 장비를 시험할 수 없다.** 전투는 「1) 공격 2) 기술 …」처럼 한 번에 한
물음이라 콘솔이 맞았다. 장비는 부위 여덟이 동시에 보여야 하고(왼손을 채우면 오른손이
잠긴다), 고칠 때마다 최종 수치가 다시 계산되며, 후보가 스무 개를 넘는다.

## 무엇을 했나

`hd_world_lab` — `dart:io` HTTP 서버 하나에 두 클라이언트.

| 누가 | 어떻게 |
|---|---|
| 사람 | `GET /` 의 장비 화면. 마우스로 사람 → 부위 → 채울 것 |
| 스크립트 | `POST /api/command`. JSON |
| 에이전트 | `GET /api/guide` 를 먼저 읽고 같은 명령 |

**서버는 규칙을 하나도 갖지 않는다.** 모델이 이미 명령과 사실로 말하므로 해석해
넘기고 이벤트와 새 상태를 그대로 싣는다.

### 한 번의 왕복

`POST /api/command` 가 `events` · `refused` · **새 상태 전부**를 함께 준다.
바꾼 뒤 다시 읽을 필요가 없다.

### 거절도 200 이다

`kind: refused` 이벤트에 닫힌 열거 `reason` 이 실린다. **400 은 JSON 을 읽을 수
없을 때만**이고, 그때는 어느 칸이 틀렸는지와 **고를 수 있는 값**을 준다:

```json
{"error":"unknown value","field":"slot",
 "allowed":["rightHand","leftHand","body","head","legs",
            "commonAmulet","classAmulet1","classAmulet2"]}
```

묶음(`/api/commands`)은 **해석을 전부 먼저** 한다. 한 항목이라도 읽히지 않으면
아무것도 적용하지 않는다 — 반쯤 바뀐 세계를 만들지 않는다.

### 화면은 한국어를 갖지 않는다

`GET /api/text` 를 한 번 받아 전부 거기서 찾는다. 그래서 이름이 화면과 터미널에서
갈릴 수 없다 — `hd_battle_text` 가 전투에 대해 지키는 것과 같은 규칙이다.

### 규격과 안내를 따로 둔다

`tools/mapEditor` 가 이미 하던 것이다. `openapi.yaml` 은 필드를 말하고
`GET /api/guide` 는 **뜻**을 말한다 — 무엇을 눌러 보면 무엇이 보이는지까지.

## 왜 별도 FE 인가 (Flutter 실험실이 아니라)

전투 실험실은 `hadar2026_app` 안의 진입점이라 Flutter SDK 와 앱 전체를 끌고 온다.
장비는 앱을 하나도 필요로 하지 않으므로 그 의존을 만들 이유가 없다. **판정의 요점이
독립성**이라, 시험 도구가 앱을 요구하면 그 요점이 흐려진다.
