## 문제

**fixture 17개 중 14개가 2인 파티다.** 실제 게임은 5인 + 소환수다.

| 파티 인원 | fixture 수 |
|---|---|
| 1인 | 2 |
| **2인** | **14** |
| 4인 | 1 |
| 5인 이상 | **0** |

이 차이는 사소하지 않다. 같은 적·같은 명령으로 측정하면:

| | 2인 | **5인** |
|---|---|---|
| 라운드 (Giant + Wolf) | 9 | **4** |
| 라운드 (Orc ×3) | 5 | **3** |
| 적 특수 능력 발동 (Basilisk ×2) | **0회** | **10회** |

두 번째 줄이 특히 크다. `consciousPlayers > 3` 게이트 때문에 **적의 특수 능력이
2인 파티에서는 한 번도 켜지지 않는다.** 같은 게이트가 적의 시전 대상 선택에도 있어
(`rng.next(consciousPlayers) < 2`) **2인이면 항상 참, 5인이면 40%** 다.

→ B1·B2 가 남긴 대역표와 감각(부록 O·U 포함)이 전부 이 판에서 나왔다.
**B5 의 어떤 측정도 이걸 고치기 전에는 근거가 약하다.**

## 무엇을 할 것인가

### 1. 5인 기준 파티를 하나 정한다

전투 규칙을 시연하는 판이므로 **역할이 갈리는 5인**이어야 한다 — 물리 위주 · 마법 위주 ·
치료 위주 · 방패 위주 · 보조. B5 가 들어오면 여기에 열과 무기 사거리가 얹힌다.

`test/support/party.dart` 의 `startingSetup` 은 **원작 시작 파티(2인)를 재현하는 것이
목적**이므로 그대로 둔다. 새 5인 판은 별도로 만든다.

### 2. fixture 를 두 벌로 나눈다

| 벌 | 목적 | 인원 |
|---|---|---|
| **원작 재현** | 원작 조우를 그대로 (`town1_pair` · `devil_hunter_x7`) | 원작대로 |
| **규칙 시연** | 확장 항목마다 하나씩 (B2 의 12개 + B5 의 것) | **5인** |

지금은 둘이 섞여 있다. 나누면 "원작과 같은가" 와 "규칙이 도는가" 를 따로 볼 수 있다.

### 3. 대역표를 5인 기준으로 다시 뽑는다

`tool/damage_band.dart` 와 부록 U 의 표. **부록 U 는 지우지 않고 "2인 기준" 이라고
표시한 뒤 5인판을 나란히 둔다** — 부록 H-2 를 구 전투식 기준으로 표시한 것과 같은 방식이다.

## 결과 (2026-09-05)

### fixture 가 두 벌로 나뉘었다

| 벌 | 개수 | 파티 |
|---|---|---|
| `fixtures/original/` | 2 | 원작 시작 파티(2인) — `town1_pair` · `devil_hunter_x7` |
| `fixtures/rules/` | 15 | **5인 기본 파티** |

5인 기본 파티는 역할이 갈린다 — 슴갈(만능·마법) · 유리(민첩) · 방패병(전위·방패) ·
술사(후위·마법) · 치유사(후위·치료). `tool/make_fixtures.dart` 의 `standardParty()` 이고
`replace` 로 슬롯만 갈아끼운다(독에 걸린 유리, HP 를 깎은 슴갈 등).

### 한 줄로 다시 만들어진다 — **이것이 이 이슈의 진짜 산출물**

`Fixture` 에 **`record` 방침 칸**을 넣었다. 예전에는 방침이 주석에만 있어서 규칙이
바뀔 때마다 fixture 마다 손으로 `--record` 를 다시 돌려야 했다(그 과정에서 명령 열을
날려먹은 적이 여러 번 있다).

```bash
dart run tool/make_fixtures.dart     # 17개를 만들고 명령 열까지 기록
```

**B5 는 난수 뽑는 순서를 여러 번 바꾼다.** 그때마다 이 한 줄이면 된다.

### 방침이 슬롯별로 갈린다

5인이 되면서 전원에게 같은 행동을 시키면 시연이 망가진다 — **다섯이 다 치료하면
아무도 적을 못 잡는다.** 실제로 `heal` fixture 가 1,438 명령에 전멸로 끝났다.

```
attack,4=heal:21      슬롯 4 만 치료. 나머지는 공격
attack,3=magic-all    술사만 전체 마법
```

### 5인이 드러낸 것 셋

| | |
|---|---|
| **도주는 일행 전체가 같이 해야 한다** | 한 사람만 도망가면 나머지 넷이 적을 먼저 잡아 승리로 끝난다 |
| **적 특수 능력이 켜졌다** | `enemy_special` 에서 7회 발동 · 행운 방어 1회. 2인에서는 0회였다 |
| **마법이 물리를 압도하는 것이 시연을 망가뜨린다** | `enemy_ai` 에서 술사가 마법 한 방(1008)으로 Wisp 을 즉사시켜 자가 치료를 볼 수 없었다. 물리로만 갉아야 임계값 언저리를 오르내린다 — 부록 U-3 의 문제가 fixture 설계에까지 나온다 |
