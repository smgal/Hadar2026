# B5-04 적의 대상 선택을 열 가중으로

- **상태**: DONE
- **구간**: B5 ([_README](_README.md))
- **성격**: **판단**
- **규모**: S
- **선행**: [B5-01](B5-01-rank-and-gap.md)
- **규격 영향**: 없음

## 문제

**적의 공격 대상이 완전 균등 난수다.**

```dart
// rules/enemy_action.dart
int pickTargetIndex({required int candidateCount, required BattleRng rng}) =>
    rng.next(candidateCount);
```

의식 있는 파티원 중 균등 추첨이다. 그래서

- 앞열·뒷열이 없고
- 마법사를 지킬 방법이 없고
- **파티 순서를 정하는 화면이 전투에 아무 영향이 없다**

**이것이 B5 전체에서 제일 큰 문제다.** 공격 쪽 결정이 얕은 것보다 **방어 쪽 결정이 0개**인
것이 더 크다. 플레이어가 "맞는 것" 에 대해 할 수 있는 일이 전혀 없다.

## 무엇을 할 것인가

균등 추첨을 **열 가중 추첨**으로 바꾼다.

```
사거리 1 무기 기준:   1열 55%  ·  2열 30%  ·  3열 15%
```

가중치는 **공격자의 사거리에 따라 달라진다** — 긴 무기는 뒤까지 고르게 닿는다.

### 이 한 줄이 만드는 것

| | |
|---|---|
| **대열이 결정이 된다** | 마법사를 뒤에 두면 안전하지만 지팡이가 안 닿는다 |
| **탱커가 성립한다** | 앞에 나온 사람이 실제로 더 맞는다 → [B5-03](B5-03-advance.md) 의 전진 방어가 뜻을 갖는다 |
| **돌격에 값이 붙는다** | 전진 공격이 별도 페널티 없이 위험해진다 |

**최소 프로토타입은 [B5-01](B5-01-rank-and-gap.md) + 이 이슈다.** 규격 변경이 `rank`
하나뿐이고, 플레이어에게 지금 없는 결정을 즉시 만들어 주고, 재미있는지를 콘솔에서 바로 볼 수 있다.
여기서 "파티 순서를 고민하게 되네" 가 안 느껴지면 방향이 틀린 것이라 크게 물리기 전에 안다.

### 아군의 대상 선택은?

**바꾸지 않는다.** 아군은 사람이 고르고, 사거리 밖은 [B5-01](B5-01-rank-and-gap.md) 의
벌점으로 처리된다. 목록에서 빼지 않는다.

## 결과 (2026-09-05)

`rules/position.dart` 의 `rankWeights` · `pickByRank`.

### 사거리 안/밖이 아니라 **거리 자체**로 감쇠한다

처음에는 "사거리 밖으로 몇 칸" 으로 가중을 줬는데, 그러면 **간격 0 에서 전부 사거리
안이라 가중이 평평해졌다.** 그런데 부록 X-1 이 말하듯 **레벨 1 조우의 100% 가 간격 0**
이다 — 초반 전투 전체에서 이 규칙이 아무 일도 안 하게 된다.

거리로 바꿨다. 사거리가 닿는다고 앞사람을 뚫고 뒤를 치기가 똑같이 쉬운 것은 아니다.
**감쇠 폭을 사거리가 정한다**(`falloffForReach`) — 창은 앞을 지나쳐 고르고 철퇴는
앞사람을 친다. 사거리가 가중치에 들어가는 자리가 여기다.

### 실측 — 앞열이 뒷열의 3배를 맞는다

전투 400판을 끝까지 돌린 것([부록 X-3](../../blueprint/_meta/GROUND_TRUTH.md)):

| 열 | 피격 비율 |
|---|---|
| 1열 | **30~31%** |
| 2열 | 20% |
| 3열 | 10% |

### 뒤에 숨는 것은 전략이 되지 않는다

전원을 3열에 세우면 가중이 **균등으로 수렴한다.** 아무도 앞에 없으면 뒤에 숨을 것도
없기 때문이고, 별도 규칙 없이 식에서 그냥 그렇게 나온다.
