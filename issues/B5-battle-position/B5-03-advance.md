# B5-03 이동 — 대열 전진 · 전진 공격 · 전진 방어

- **상태**: DONE
- **구간**: B5 ([_README](_README.md))
- **성격**: **판단**
- **규모**: L
- **선행**: [B5-02](B5-02-weapon-reach.md)
- **규격 영향**: 없음 — 전투 내부에서 끝난다

## 문제

`rank` 와 `gap` 이 있어도 **바꿀 방법이 없으면** 조우가 정한 위치로 끝까지 싸운다.

그런데 이동을 어떻게 값 매기느냐에서 시스템이 갈린다.

| | 결과 |
|---|---|
| 공짜 | 전원이 즉시 붙는다 → 2라운드부터 위치가 사라진다 |
| 각자 턴을 씀 | 3~4라운드 전투에서 아무도 안 쓴다. 긴 무기가 선택이 아니라 필수가 된다 |

## 무엇을 할 것인가

### 1. 대열 전진/후퇴 — 라운드 개시 단계, 리더의 턴

**행동 순서 안의 한 턴이 아니라 라운드 개시 단계**다. 그래서 민첩 선제(B2-05)를 안 건드린다.

- 리더(슬롯 0)가 명령하고, **그 라운드에 공격하지 않는다** — 그것이 값이다
- 간격이 **모두가 행동하기 전에** 확정되므로 명령을 세울 수 있다
- 원작 메뉴에서도 슬롯 0 만 7번 자리가 다르다(`order == 0` 이면 자동 전투, 아니면 도망).
  **리더가 진형을 움직이는 사람**이라는 자리가 이미 있다

양측이 서로 다른 명령을 내면 **더하고 상한을 건다**:

| 아군 | 적 | 결과 |
|---|---|---|
| 전진 −1 | 후퇴 +1 | **0 — 맞받았다** |
| 전진 −1 | 전진 −1 | −2, 양쪽이 달려들었다 |
| 전진 −1 | 없음 | −1 |

난수가 없고 읽힌다. "저쪽이 내 움직임을 받아쳤다" 가 화면에 그대로 나온다.

**5인에서 값이 맞는다** — 5명 × 4라운드 = 20행동 중 1개, **5%** 다. 2인이었다면 12% 였다.

### 2. 일부 전진 — 본인의 턴

자기 `rank` 만 −1. 진형에서 혼자 앞으로 나온다.

### 3. 전진 공격 (돌격) — 이동이 곧 공격

특정 무기만 가능하고, 그중 특화된 것이 있다(기병창).
**값을 따로 설계할 필요가 없다** — 앞으로 나오면 열이 앞당겨지고,
[B5-04](B5-04-rank-weighted-targeting.md) 의 열 가중 때문에 **그 사람이 화살받이가 된다.**
돌격하면 맞는다.

### 4. 전진 방어 — **이 구간에서 제일 중요한 것**

지금 **탱커가 성립하지 않는다.** 적 대상 선택이 균등 난수라 방패를 아무리 좋게 해도
적이 그 사람을 안 때린다. 방패는 자기만 지킨다.

**열 가중 대상 선택 + 전진 방어**를 같이 넣으면:

> 앞으로 나오는 것이 곧 화살받이가 된다 → **탱킹이 저절로 성립한다**

위치 · 대상 선택 · 방패 **셋이 하나가 된다.** `shieldBlocks`(B2-08, `maxShieldBlock = 75`)가
이미 있어서 붙일 자리도 있다.

| | |
|---|---|
| 다음 피격 | 방패로 막을 확률이 비약적으로 오른다 |
| **같은 라운드 2번째 피격** | 확률이 떨어진다 — 없으면 탱커가 무적이 된다 |
| **밀림 면역** | 버틴다. 이름값을 한다 ([B5-07](B5-07-knockback.md)) |

밀림 면역에는 뜻밖의 소득이 있다 — **버틴 탱커는 간격을 붙잡아 둘 수 있다.**
적이 우리 앞열을 밀어내 거리를 벌리려 해도 통하지 않는다.

라운드 안에서 피격 횟수를 세는 새 상태가 필요하다. 싸다.

## 결과 (2026-09-05)

메뉴에 항목 넷이 늘었다 — `advanceFormation` · `retreatFormation` · `charge` · `brace`.

### 대열은 턴이 아니라 **단계**다

행동 순서 안에 넣으면 **리더가 항상 제일 빨라야** 하고, 그러면 B2-05 의 민첩 선제가
무너진다. 명령을 다 모은 뒤 **아무도 움직이기 전에** 양측 명령을 동시에 해결한다.
그래서 간격이 정해진 상태로 라운드가 굴러가고 선제는 그대로다.

양측 명령을 **더하고** 상한을 건다 — 난수가 없다.

```
일행이 물러섰다, 적이 밀고 들어왔다 — 간격은 그대로 1
```

맞받은 것이 화면에 그대로 나온다. 리더는 그 라운드에 공격하지 않고, 5인에서 그것은
전투 20행동 중 하나다.

적 쪽은 `formationWant` 이 **사거리 비교**로 정한다 — 사거리가 짧으면 붙고, 길면 벌린다.

### 돌격은 값을 따로 설계할 필요가 없었다

앞으로 나서면 열이 앞당겨지고, [B5-04](B5-04-rank-weighted-targeting.md) 의 열 가중
때문에 **실제로 더 맞는다.** 그리고 기병창으로 돌격하면 붙는 순간
**자기 무기가 안 맞는 거리**가 된다 — fixture 에서 돌격 직후 피해가 13 에서 2 로
떨어지는 것이 보인다. 자기 균형이 잡히는 고리다.

### 전진 방어가 탱커를 만든다

방패 확률을 크게 올리고(첫 피격 +45, 같은 라운드 두 번째 +12) **밀림 면역**이다.
두 번째 피격이 약해지지 않으면 무적이 되고, 무적인 탱커는 결정이 아니다.

밀림 면역에 뜻밖의 소득이 있다 — **버틴 앞열은 간격을 붙잡아 둘 수 있다.**

### 메뉴가 못 하는 것을 내놓지 않는다

돌격은 돌격 가능한 무기 + 앞에 설 자리가 있을 때만, 대열 이동은 판 안에서만.
`castableSpells` 가 못 쓰는 마법을 빼는 것과 같은 자리이고, **헛턴이 메뉴를 통해
도달 불가능**하다는 뜻이다.
