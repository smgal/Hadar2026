# B5-06 물리 속성 — 베기 / 찌르기 / 타격

- **상태**: DONE
- **구간**: B5 ([_README](_README.md))
- **성격**: **판단** — 원작에 속성 개념이 없다 (B2-09 가 마법 쪽을 이미 만들었다)
- **규모**: L
- **선행**: [B5-02](B5-02-weapon-reach.md) · [B5-05](B5-05-damage-chain.md)
- **규격 영향**: **있음** — `Element` 에 세 항목이 는다

## 문제

B2-09 가 마법에 6속성(fire/ice/lightning/force/mind/poison)과 적 21종 표를 만들었다.
**물리는 전부 무속성이다.** 그래서 무기 10종을 구분할 축이 위력밖에 없다.

## 무엇을 할 것인가

### ⚠ 속성을 **무기에 박으면 안 된다**

포켓몬의 가위바위보가 되는 이유는 **자유롭게 교체**하기 때문이다. 무기는 장비다.
적이 내 속성에 강하면 그 전투 내내 답이 없고, **그건 전략이 아니라 벌금**이다.

→ **속성은 [B5-02](B5-02-weapon-reach.md) 의 공격 방식에 붙는다.**

```
창  →  찌르기(사거리 김)  또는  후려치기(타격, 사거리 짧음)
검  →  베기(강)          또는  찌르기(중)
철퇴 →  타격만
```

상성이 **매 턴의 선택**이 되고, 사거리와 같은 물건 위에 얹힌다.

**대가**: 공격 메뉴 1번이 **베기/찌르기/타격 셋으로 갈라진다.** DQ 근간(라운드 시작
일괄 명령)은 유지되지만 메뉴가 한 겹 깊어진다. **이것을 받아들이는 것이 이 이슈의 전제다.**

### 표는 **한 벌**이어야 한다

`Element` 에 slash / pierce / blunt 를 더해 **9속성 한 벌**로. 별도 체계로 만들면
상성표가 두 벌이 되고 플레이어가 두 벌을 외워야 한다.

비용: 75종 × 9 = **675칸.** 전부 손으로 못 쓴다. 지금 `enemyAffinities` 가 21종만
채워져 있는 것도 같은 이유였다.

→ **종류별 자동 배정 + 이름 있는 20종만 손질.**

| 종류 | 기본 |
|---|---|
| 언데드 (해골·좀비) | 베기 저항 · 타격 약점 |
| 화염체 (Salamander·Hell Fire) | 화염 저항 · 냉기 약점 |
| 곤충 | 화염 약점 |
| 갑주를 두른 것 | 베기·찌르기 저항 · 타격 약점 |
| 무른 것 (Slime·Astral Mud) | 타격 저항 · 베기 약점 |

### ⚠ ×2 / ÷2 로는 "큰 특징" 이 되지 않는다

DQ 근간에는 **프레스 턴(SMT)이 없다.** 약점을 찔러도 **피해가 늘 뿐**이고 그건 계산이지
사건이 아니다. SMT 에서 약점이 재미있는 것은 **턴을 하나 더 주기 때문**이다.

> ### 답: 약점을 찌르면 **한 열 밀린다** ([B5-07](B5-07-knockback.md))

**이것이 B5-06 과 B5-01 을 하나의 시스템으로 묶는 고리다.**

- 타격으로 앞열 졸개를 밀어낸다 → 뒤의 보스가 드러난다
- 밀려난 적은 다음 턴 근접 공격이 안 닿는다 → 시간을 번다
- 창은 밀어내도 여전히 닿는다 → 장병기의 존재 이유가 하나 더 생긴다

**조합해서 붙인 것이 아니라 설계된 것처럼 느껴지는 지점이다.**

### 연계는 순서가 아니라 **상태**에 건다

민첩 선제(B2-05)를 유지하므로 **순서에 거는 연계는 복권이 된다.**

| | |
|---|---|
| ✗ | "밀어낸 **직후의** 공격은 강하다" — 누가 먼저 움직이냐에 걸린다 |
| ✅ | "**밀려난 상태의** 적은 다음 피격 시 추가 피해" — 순서와 무관 |

페르소나의 다운, 다키스트 던전의 표식이 이 방식이다.

### 체질 6종이 75행을 덮는다

675칸을 손으로 못 쓰니 **체질**을 능력치와 이름에서 읽는다 — 살 43 · 언데드 12 ·
갑주 8 · 무형 5 · 벌레 4 · 정령 3. **약점이 없는 적이 0종**이라 어떤 무기든 답이 있다.

살이 절반 이상이라 **베기가 기본값**이고, 언데드·갑주 앞에서 검이 갑자기 안 듣는다.
그때 두 번째 답을 들고 있느냐가 결정이다.

### 속성은 무기가 아니라 공격 방식에 붙었다 (B5-02 가 이미 그렇게 만들었다)

장검은 베기(1~2)와 찌르기(0~1)를 둘 다 하고, 창은 찌르기와 자루 타격을 한다.
그래서 상성이 **장비 잠금이 아니라 거리에 따라 갈리는 것**이 됐다.

### 넉백을 타격으로 좁혔다 — 한 번 고친 것

처음에는 **모든 약점**이 밀어내게 했다. 그런데 살 43종이 베기에 약하므로
**가장 흔한 공격이 곧 가장 흔한 밀어내기**가 되어 라운드마다 줄이 여러 번 움직였다.
이동원이 이미 넷인데 다섯째가 상시로 터지면 위치를 계획할 수 없다.

타격으로 좁히니 드물어서 읽히고, 철퇴와 창 자루에 다른 무기가 못 하는 일이 생기고,
설명이 따로 필요 없다 — 곤봉은 사람을 넘기고 칼자국은 안 넘긴다.

### 연계는 상태에 건다

`staggered` 표식. 민첩 선제를 유지하므로 "밀어낸 **직후**" 로 만들면 복권이 된다.
표식은 그 진영의 다음 라운드 시작에 지워져 **한 라운드짜리**다.

## 남긴 것

**공격 방식을 사람이 고르지 못한다.** 거리에 맞는 것이 자동으로 뽑힌다.
메뉴를 베기/찌르기/타격으로 가르면 "이 적에게는 타격" 이 매 턴의 선택이 되지만,
메뉴가 한 겹 깊어진다 — 받아들일지 정한 뒤에 할 일이다.

RPG 쪽 아이템 속성 배선(B3-03).
