## 문제

솔버(P2-05)는 **추상화 안에서만** 증명한다. 추상화가 버린 축(HP·food 고갈·좌표 잠금)이 실제로는
진행을 막을 수 있고, 솔버는 그것을 원리적으로 볼 수 없다(BP-34 L-8). 시뮬레이터(P2-04)는
주어진 입력만 재생하므로 **아무도 상상하지 않은 순서**를 시도하지 않는다.

그 사이에 남는 결함이 7종이다(BP-34 §6.1): 크래시 · 데드락 · 무한 대화 · 계약 위반(INV/TR assert) ·
도달 불가 콘텐츠 · 자원 소진 · 에셋 미스. 이것들은 모두 **"굴려 봐야만"** 나온다.

전제 조건이 결정론이다. `Random()` 이 시드 없이 14곳에 있고(부록 C-4) 독 데미지가 벽시계로
결정되는 동안은 같은 시드가 같은 트레이스를 내지 않으므로, 실패를 재현할 수도 최소화할 수도 없다.
P0-10·P0-11 이 이것을 고친다.

## 무엇을 할 것인가

결함 7종의 탐지 조건, 절차, 커버리지 지표 11종의 목표치는
[BP-34 §6](../../blueprint/34_headless_sim_and_solver.md) 에 있다.

**배치**: `hadar2026_app/test/harness/sim_policy.dart` 의 `RandomPolicy(seed)` +
`tools/content_cli/fixtures/regressions/`. 실행은 P2-04 의 `SimDriver` 를 그대로 쓴다 —
퍼저는 **새 실행기가 아니라 정책 하나 + 집계·최소화 코드**다.

| # | 구현 단위 | 내용 |
|---|---|---|
| 1 | `RandomPolicy(seed)` | `SimPolicy` 구현. 이동·메뉴 선택·대화 선택지를 시드 난수로 |
| 2 | 고정 코퍼스 | 시드 32개를 **소스에 박는다**. 매번 새로 뽑으면 CI 가 플레이키해진다. 새 시드는 야간 잡에서만 |
| 3 | 회귀 코퍼스 | 실패 시드를 `fixtures/regressions/seed_<hex>.json` 으로 **영구 보존**. 고쳐진 뒤에도 계속 돈다 |
| 4 | 델타 디버깅 | 실패 트레이스의 입력열을 이분 축소해 **최소 재현 시퀀스**를 찾는다. 각 후보를 `scripted` 로 재생해 같은 실패가 나는지 확인 |
| 5 | 집계 리포트 | 커버리지 11종 + 크래시·데드락·assert 건수 |

**게이트 규약**(BP-34 §6.3) — 이 구분을 흐리지 않는다:
- **하드**: 크래시 0 · 데드락 0 · 계약 위반 0.
- **소프트(경고)**: 커버리지 11종 전부. 커버리지는 맵 크기·앵커 밀도에 좌우되어 콘텐츠가 늘면
  자연히 떨어지므로, 하드로 걸면 **무의미한 앵커 추가로 게임하게 된다.**
- `greedy` 정책 1회 실행 결과를 퍼징 집계에 합산한다 — 랜덤이 못 닿는 깊은 앵커를 greedy 가 채운다.

**오탐 처리는 절차로 고정한다**(BP-34 §11.4): 재생 → 최소화 → 분류(FP-1 하네스 버그 /
FP-2 추상화 과다 / FP-3 미확정 오독 / 진짜 결함) → 억제 → 기록. 최소 재현이 3스텝이면 대개
하네스 버그이므로 **먼저 `harness_self_test.dart` 가 통과하는지 본다.**

## 착수 조건

GATE-1 통과 + P2-04 완료 + P0-10·P0-11 완료(결정론).

**왜 그 전에는 안 되는가**: 퍼저의 산출물은 "시드 0x0000A3F1 에서 47스텝째 크래시" 다.
결정론이 없으면 그 문장이 **거짓**이 된다 — 같은 시드로 다시 돌려도 재현되지 않으므로
델타 디버깅이 성립하지 않고, 회귀 코퍼스는 무작위로 켜졌다 꺼지는 플레이키 테스트가 된다.
그리고 퍼저가 찾는 것은 **콘텐츠 양이 많을 때의 조합 결함**이다. 퀘스트 5개라면 32시드 랜덤보다
사람이 한 번 플레이하는 것이 커버리지가 높다.

## GATE-1 이 보류/취소로 판정되면

- **버려지는 것**: 커버리지 지표 11종과 목표치, 야간 전량 잡, 32시드 배치 집계.
  전부 "사람이 다 볼 수 없는 물량" 을 전제한다.
- **그래도 남는 값**:
  - **크래시·데드락·계약 위반 3종의 하드 검사**는 콘텐츠 양과 무관하다. 이것은 게임 엔진의
    안정성 테스트이고, 손으로 만든 퀘스트 1개짜리 팩에서도 `_isScriptRunning` 재진입 가드나
    narrative 중첩 버그를 잡는다. 취소 시 시드 4개짜리 **스모크**로 축소해 남긴다.
  - 델타 디버깅과 회귀 코퍼스는 **버그 리포트 도구**로 값이 있다 — "이 순서로 누르면 깨진다" 를
    최소 재현으로 커밋할 수 있게 된다. AI 와 무관한 이득이다.
  - 에셋 미스 검출(FZ-7)은 부록 A-1(존재하지 않는 cm2 경로가 무조건 부여됨) 계열 사고의
    재발 방지 장치다.

## 완료 판정 기준

**[잠정 — GATE-1 통과 시 확정]**

- [ ] 고정 32시드가 소스에 박혀 있고, 같은 시드가 **두 번 돌려 같은 트레이스**를 낸다
- [ ] 크래시·데드락·계약 위반이 발견되면 종료 코드 1(하드 실패)이다
- [ ] 커버리지 미달은 종료 코드 0 + 경고다(소프트)
- [ ] 인위적으로 심은 결함(무한 대화 1건 · 회복 경로 없는 아이템 소실 1건)을 32시드 안에 잡는다
- [ ] 실패 시드가 `fixtures/regressions/seed_<hex>.json` 으로 저장되고 다음 실행에 자동 포함된다
- [ ] 델타 디버깅이 최소 재현 시퀀스를 내고, 그 시퀀스를 `scripted` 로 재생하면 같은 실패가 난다
- [ ] `MemoryAssetSource.misses` 가 비어 있지 않으면 실패로 보고된다(FZ-7)
- [ ] `GameReloadException` 과 종료 요청은 크래시로 집계되지 **않는다**

## 하지 않을 것

- 콘텐츠 품질·서사 판정. 퍼저는 "깨지는가" 만 본다.
- 커버리지를 하드 게이트로 거는 것. 명시적으로 기각한다(BP-34 §6.3).
- 무작위 시드 생성(PR 잡). 야간 잡에서만 추가한다.
- 결정론 수리 자체 — P0-10·P0-11.
- 솔버 판정과의 통합 리포트 — P2-09(CI 통합) 소관.
