# B6 — 전투 메뉴·행동 현대화 (**완료** 2026-09-06 · 8/8)

> **신설 (2026-09-06, [9차 판정](../DECISION-LOG.md))**
> 원작의 전투 메뉴를 더 이상 고집하지 않는다. **1990년의 메뉴 구조**를 버리고
> 지금 사람이 읽을 수 있는 것으로 다시 짠다. 규칙은 B1·B2·B5 가 만든 것을 그대로
> 쓰되, **무엇을 언제 물어보는지**를 바꾼다.

규격은 **CONTRACT v2 → v3**.

## 무엇이 문제였나

행동 메뉴가 최대 13줄이었고, 그중 **다섯 줄이 마법**이다.

```
1) 한 명의 적을 단도로 공격
2) 한 명의 적에게 마법 공격      ┐
3) 모든 적에게 마법 공격         │  마법이 넷으로 쪼개져 있다.
4) 적에게 특수 마법 공격         │  무엇이 어디 있는지 외워야 쓴다.
5) 일행을 치료                   ┘
6) 적에게 초능력 사용            ← 다섯 번째 갈래
7) 물건을 사용
8) 앞으로 파고들며 공격
9) 앞에 서서 버팀
10) 일행에게 무조건 공격 할 것을 지시 / 도망을 시도함
11) 일행 전체가 앞으로
12) 일행 전체가 물러남
```

**갈래가 곧 메뉴 줄이 되어 있었다.** 원작은 마법 45종을 번호대로 나눠 놓았고,
그 나눔이 그대로 최상위 메뉴가 됐다. 나눔의 기준은 "무엇을 하는가" 가 아니라
**"몇 번대인가"** 다. 그래서 성격이 전혀 다른 것이 한 갈래에 들어가 있다 —
`특수 마법` 안에 **독**(상태이상)과 **능력 저하**(정신계)가 함께 있다.

## 새 구성 — 최상위 여섯 줄

```
⚔  공격              무기로 한 명을 친다 (파고들기는 조건이 맞을 때 여기 옆에)
✨  기술              마법 45종 + 초능력을 한 목록으로. emoji 가 범주를 말한다
🎒  물건              회복약 · 무기에 바르는 것
🛡  버팀              앞에 서서 막는다
🏃  도망              파티 전체. 리더가 낸다
⚙  지시              대열 전진·후퇴 · 자동 전투 (리더 전용)
```

13 → **6**. 그리고 **읽는 데 기억이 필요 없다.**

### 기술 목록은 하나다 — emoji 가 범주를 말한다

```
🎯 마법 화살           SP 1
🎯 독 바르기           SP 10      ← 대상이 적이 아니라 내 무기다
💥 공기 폭풍           SP 4
☠ 방어 무력화          SP 15
💚 한명 치료           SP ~
💞 모두 치료           SP ~
🔮 염력                ESP 10
```

| emoji | 뜻 |
|---|---|
| 🎯 | 적 한 명 |
| 💥 | 적 전체 |
| ☠ | 적을 약하게 (지속) |
| 💚 | 아군 한 명 |
| 💞 | 아군 전체 |
| 🌀 | 자신 · 자기 무기 |
| 🔮 | 초능력 (ESP 를 쓴다) |

**목록이 길어지는 것은 받아들인다.** 마법 레벨이 높으면 30줄이 넘지만, 갈래를 고르는
단계가 사라져서 **누르는 횟수는 오히려 줄어든다**(2단계 → 1단계). DQ·FF 도 주문 목록은
길게 하나로 둔다.

## 왜 지금인가

**전투 실험실(B4-01)이 생겨서 눌러 볼 수 있게 됐다.** 메뉴 구조는 수치가 아니라 손에
닿는 문제라, 재는 도구가 아니라 **누르는 도구**가 있어야 판단할 수 있었다.
