# B6-03 무기에 바르기 — 독 · 마비 · 화염

- **상태**: DONE (2026-09-06)
- **구간**: B6
- **규모**: M
- **선행**: B6-02 · [B6-05](B6-05-party-consumables.md)

## 착상

> "검에 독을 바르는 것으로 인해 무기에 속성 부여라는 개념도 생기게 되는데"

B5-06 이 물리에 속성을 넣었다 — 베기·찌르기·타격. 그건 **무기가 타고난 것**이라
바꿀 수 없다. 도포는 그 위에 **한동안 얹는 것**이다.

## 규칙

```dart
enum Coating { poison, paralysis, fire }

class WeaponCoating {
  final Coating kind;
  int rounds;        // 남은 라운드
}
```

| 도포 | 명중했을 때 | 지속 |
|---|---|---|
| 🟣 독 | 피해와 별개로 적에게 **독**을 건다 (저항으로 막힌다) | 3 라운드 |
| ⚡ 마비 | 확률로 적의 **다음 행동을 지운다** — `staggered` 와 같은 자리 | 3 라운드 |
| 🔥 화염 | 피해에 **화염 속성**을 얹는다 — 약점 ×2 / 저항 ÷2 | 3 라운드 |

### 왜 3 라운드인가

실전이 **3~4 라운드**다(부록 W). 한 라운드면 바르는 턴이 아깝고, 전투 내내면
바르지 않을 이유가 없어진다. **한 번 발라 두면 남은 전투의 대부분에 걸리되,
바르는 턴 하나를 낸다** — 그 교환이 성립하는 길이가 3이다.

### 겹쳐 바를 수 없다

새로 바르면 **덮어쓴다.** 세 속성이 동시에 걸리면 계산이 곱해지고, 무엇 때문에
이겼는지 알 수 없게 된다.

### 화염은 **이미 있는 상성표를 탄다**

`affinity.dart` 의 `Element.fire` 를 그대로 쓴다. 새 표를 만들지 않는다 —
언데드가 화염에 약하다는 것이 이미 적혀 있다.

### 마비는 `staggered` 와 다른 칸에 둔다

`staggered`(밀린 표식)는 **연계**를 위한 것이고 마비는 **행동 박탈**이다.
같은 칸을 쓰면 넉백이 마비를 지운다.

## 결과 (2026-09-06)

`rules/coating.dart` — `Coating {poison, paralysis, fire}` · `WeaponCoating` ·
`coatingRounds = 3` · `coatingTakesHold` · `paralysisChancePercent = 50`.

| 도포 | 명중 뒤 | 근거 |
|---|---|---|
| 🟣 독 | `resistance` 굴림 통과 시 `poison += 1` — 마법 13 과 같은 단위 | `_applyCoatingOnHit` |
| ⚡ 마비 | 저항 통과 후 **50%** 로 `paralyzed`. 그 적의 다음 턴이 사라진다(`EnemyLostTurn`) | 매 타 마비면 한 명이 적을 영원히 묶는다 |
| 🔥 화염 | 그 타격의 원소가 `Element.fire` 로 — 기존 상성표 그대로 | `coatingElement` |

카운트다운은 라운드 시작에(`_beginRound`), **바른 라운드 다음부터**. 그래서 3 은
실제로 휘두르는 라운드 수다. 새로 바르면 덮는다. 마비는 `staggered` 와 다른 칸이라
넉백이 지우지 않는다.

두 길: 마법 13(SP 10) 과 `poison_vial`·`paralysis_vial`·`fire_vial`(소비 1).
`hd_battle_console/fixtures/rules/coating.json` 이 둘을 한 판에 보여 준다.

### 병은 던질 수도 있다 (2026-09-06 추가)

실제로 눌러 보니 화염병을 고르면 **적을 고르라고 물은 뒤 무기에 발랐다** — 묻는 것과
하는 것이 달랐다(`_answerItem` 이 도포병을 결정 쪽 분기에 넣지 않았다). 고치면서 병에
길을 하나 더 냈다: 고른 뒤 `ItemUseDecision` 으로 **🗡 바른다(3턴) / 🎯 던진다(지금 한 번)**
를 묻는다.

| 던지면 | |
|---|---|
| 🔥 화염병 | 한 명에게 화염 **30** (`vialThrowDamage`) — 결정(40)과 검 한 번(~10) 사이 |
| 🟣 독병 · ⚡ 마비병 | 발린 무기로 **한 번 때린 것과 같은 효과** (저항 굴림 → 독 +1 / 50% 마비) |

던지기는 즉시·한 번, 바르기는 한 턴 쓰고 세 라운드. 콘솔 방침 `throw`.
