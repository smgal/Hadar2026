# B2-11 초자연 시전 — 적 소환과 파티원 탈취

- **상태**: DONE
- **구간**: B2 — **잠정 항목** ([_README](_README.md))
- **성격**: **판단** — 구조는 C++, 값·확률은 우리가 정한다 ([6차 판정](../DECISION-LOG.md))
- **규모**: L
- **선행**: [B2-07](B2-07-enemy-behavior.md)
- **설계 근거**: [`GROUND_TRUTH` 부록 T-6](../../blueprint/_meta/GROUND_TRUTH.md)

## 왜 B2-07 에서 뗐나

`enemyCastSpellWithSpecialAbility` 의 2단이 **파티원을 적으로 끌어간다.**
파티 구성이 전투 중에 바뀌면 모드 인계 규격이 달라진다 —
[B2-10](B2-10-esp-abilities.md) 의 독심(적을 파티로)과 **정확히 반대 방향의 같은 문제**다.
둘을 같이 설계해야 규격이 한 번에 닫힌다.

## 문제

`specialCastLevel` 은 지금 **읽는 곳이 0곳**이다(부록 O). B2-07 이 디스패처를 옮기면서
"초자연 능력을 사용했다" 줄만 내고 효과는 비워 뒀다.

원작에서는 이 필드가 **한 턴에 두 번 행동**시키는 값이고(부록 T-1), 그 추가 행동이 아래 3단이다.

## 무엇을 할 것인가

`special_cast_level` 이 쌓이는 3단이다. 낮은 단은 높은 단에서도 계속 굴러간다.

### 1단 (≥1) — 적 소환

무리가 줄면(`num_not_dead < random(3)+2` 이고 `random(3)==0`) 새 적을 부른다:

```cpp
registerEnemy(p_enemy->ed_number + AvejUtil::random(4) - 20);
```

**자기보다 20 낮은 근처의 변종**을 부른다 — 즉 자기보다 약한 것.
적 목록에 자리가 없으면 이미 죽은 슬롯을 덮어쓴다.

**⚠ `ed_number` 가 어느 인덱스 공간인지 확인해야 한다** — `s_enemy_data[75]`(0-based)라면
`ed_number - 20` 이 음수가 될 수 있다(id 20 미만인 적). 가드가 필요하고, 원작이
그 경우를 어떻게 처리했는지(또는 안 했는지) 확인할 것. 부록 P-4 와 같은 함정이다.

### 2단 (≥2) — 파티원 탈취

`num_not_dead < 7` 이고 `random(5)==0` 이면 **마지막 유효 파티원**을 적 목록에 복사하고
그 파티원의 이름을 지운다(`setName("")` = 슬롯 무효화).

**규격 항목이 필요하다** — `BattleOutcome` 에 "이탈한 파티 슬롯" 을 실어야 한다.
[B2-10](B2-10-esp-abilities.md) 의 "합류한 파티원" 과 짝이다.

### 3단 (≥3) — 전체 즉사 판정

`special != 0` 이고 `random(5)==0` 이면 파티 전원에게 민첩·행운 판정을 거쳐 즉사를 건다.
판정은 특수 능력 3번과 같다(부록 T-4).

## 정할 것

- **소환된 적의 경험치·골드**가 정산에 포함되는가? 무한 소환으로 경험치를 벌 수 있으면 문제다
- 탈취된 파티원이 **전투 후 돌아오는가?** 원작은 이름을 지웠을 뿐이라 세이브에 어떻게 남는지 확인 필요
- 소환 상한 — 원작은 `enemy.capacity()` 로 막았다. 우리 쪽 상한을 정해야 한다

## 결과 (2026-09-05)

`packages/hd_battle/lib/src/rules/superhuman.dart`.

3단이 쌓이고 낮은 단은 높은 단에서도 계속 굴러간다 — 소환 · 탈취 · 전체 즉사.

**정한 것 세 개** (원작에 답이 없던 것들)

| 물음 | 답 | 이유 |
|---|---|---|
| `ed_number - 20` 이 음수면? | 소환하지 않는다 | 원작은 검사하지 않아 음수 인덱스가 된다 |
| 소환 상한 | `시작 적 수 × 3`, 최소 8 | 원작은 C++ 벡터의 여유 공간으로 막았다 — 규칙이 아니라 구현 사정이다 |
| 소환된 적의 경험치·골드 | **없다** | 매 턴 소환하는 적이 무한히 지불하게 된다 |

**규격 항목 하나가 생겼다** — `BattleOutcome.departedSlots`.
죽음이 아니라 **부재**이므로 `dead` 와 따로 나간다. B2-10 의 `recruits` 와 짝이다.

## 완료 판정 기준

- [x] `specialCastLevel > 0` 인 적이 초자연 시전 **뒤에 일반 행동까지** 한다
- [x] 1단이 적을 소환하고, 소환 id 가 테이블 범위를 벗어나지 않는다
- [x] 2단이 파티원을 이탈시키고, 그것이 `BattleOutcome` 에 실린다 (**새 규격 항목**)
- [x] 3단의 즉사 판정이 민첩·행운을 읽는다
- [x] 소환 상한이 있고, 무한 소환으로 경험치를 벌 수 없다
