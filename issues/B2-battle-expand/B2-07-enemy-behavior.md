# B2-07 적이 자기 능력에 맞는 행동을 고른다

- **상태**: DONE
- **구간**: B2 — **잠정 항목** ([_README](_README.md))
- **성격**: **판단** — 구조는 C++, 버그 3건은 고쳤다 ([6차 판정](../DECISION-LOG.md))
- **규모**: M
- **선행**: B1 전체 · [B2-01](B2-01-magic-effects.md) · [B2-03](B2-03-status-effects.md)
- **설계 근거**: [MILESTONES §7](../MILESTONES.md)

## 문제

적 행동이 사실상 없다 — `battle.dart:501-530`:

- 대상은 무작위 — `:504` `targets[Random().nextInt(targets.length)]`
- `special > 0 || castLevel > 0` 이면 `"마법/특수 능력을 사용했다!"` **한 줄**과
  `:518` `(e.level * 5) + Random().nextInt(10)` 의 단일 피해식으로 끝난다
- `:507-510` 의 물리/특수 선택 판정은 `Random().nextInt(acc*1000+1)` 두 개를 비교하는데,
  분기 안이 비어 있다(`// Physical preferred by roll` 주석만)

즉 `specialCastLevel` 은 어디서도 읽히지 않고, 75종의 적이 사실상 두 종류로 동작한다.

## 결과 (2026-09-05)

`packages/hd_battle/lib/src/rules/enemy_ai.dart`. 근거는
[`GROUND_TRUTH` 부록 T](../../blueprint/_meta/GROUND_TRUTH.md).

### 디스패처가 잃고 있던 것 둘

- **`specialCastLevel` 이 있는 적은 한 턴에 두 번 행동한다.** 초자연 시전 뒤에 `return` 이
  없다. 그 필드는 Dart 에서 읽는 곳이 0곳이었다 — 이것이 용도다.
  시전 자체의 효과는 [B2-11](B2-11-superhuman-casting.md) 이 맡는다(소환·탈취라 규격이 바뀐다)
- **특수 능력은 의식 있는 파티원 4명 이상**이어야 나온다. **시작 파티(2명)로는 절대 안 나온다** —
  적이 단조롭게 느껴진 큰 이유다

### 마법이 `cast_level` 1~6 사다리다

레벨이 올라갈수록 대상 선택이 영악해지고(무작위 → 의식 있는 → 가장 약한),
자기 치료 → 동료 전체 치료 → 파티 방어구 갈아내림이 차례로 열린다.

**적이 동료를 치료하고 되살린다** — 회복량은 자기 `레벨 × 정신력 / 4`, 동료 `/ 6` 이고,
치료가 `dead` 를 먼저 지우므로 **한 번에 한 단계씩 부활**시킨다.

### 특수 능력 3종에서 행운이 처음 일을 한다

독(1) · 기절(2) · 즉사(3). 판정 2단 — `random(범위) > 적 민첩` 실패,
그다음 `random(20) < 대상 행운` 회피. **시작 파티는 행운이 0 이라 하나도 못 막는다.**

즉사(3)는 `NOT_DEAD` 를 노리므로 **쓰러진 파티원도 안전하지 않다** — 2단계 붕괴(B2-04)가
의미를 갖는 나머지 절반이다.

## C++ 버그 3건 — 전부 고쳤다

| 무엇 | 왜 버그인가 |
|---|---|
| `average_ac` 가 파티가 아니라 **적 자신의 ac** 를 더한다 | `(*obj)->ac` 여야 할 것이 `p_enemy->ac` 다. 파티 무장과 무관하게 판정된다 |
| 방어구 갈아내리기 루프가 `player.begin()+1` 에서 시작 | **슬롯 0 은 절대 안 깎인다.** 초기화도 없다 |
| `case 5` 의 가장 약한 대상 탐색이 `isConscious` 를 안 본다 | 빈 슬롯이나 죽은 사람을 고를 수 있다. **`case 6` 은 같은 탐색을 센티널과 `isConscious` 로 제대로 한다** — 고친 형태가 원작 자신의 것이다 |

세 번째가 가장 강한 증거다. 같은 파일에서 같은 탐색을 두 번 쓰는데 한쪽만 맞다.

## ⚠ 자동 전투는 이 이슈가 아니다 — 그런데 C++ 이 버그를 자백해 놨다

`hd_base_game_main.cpp` 의 자동 전투(`case 8`)는 **직업별 분기**이고, 직업 3 의 대상 선정에
C++ 자신의 주석이 붙어 있다 — `// @@ dead 맞나?` 아래에서 **의식이 있고 죽은 적**(존재할 수 없다)을
고른다. 루프도 0번 적을 건너뛴다. 자세한 것은
[`GROUND_TRUTH` 부록 R-6](../../blueprint/_meta/GROUND_TRUTH.md).

현재 Dart 는 자동 전투를 "첫 생존 적 물리 공격" 으로 뭉갰다(`battle.dart:377-382`).
**이식할 때 그 두 줄은 고친다.** 이 이슈가 받을지 별 이슈로 뺄지는 착수 시 판단한다.
