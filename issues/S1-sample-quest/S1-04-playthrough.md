## 문제

만든 것이 실제로 도는지는 **플레이로만** 알 수 있다. cm2 의 실패는 대부분 **조용하다**(§9 침묵 실패 모드) —
`Unknown function` 은 콘솔에만 찍히고 화면에는 "NPC 가 같은 말을 반복한다" 로만 나타난다.
그리고 세이브·로드 경로에는 이미 검증된 결함이 둘 있다(부록 C-1·C-2).

## 왜 지금 해야 하는가

- [MILESTONES §2](../MILESTONES.md) 의 완료 판정 6개가 **이 이슈에서만** 관측된다.
- [S3-01](../S3-generation/S3-01-quest-spec-format.md) 이 이 산출물을 정답지로 삼는다. 돌지 않는 정답지는 정답지가 아니다.

## 무엇을 할 것인가

### 1. 실행 방법 (데스크톱)

```bash
cd hadar2026_app
flutter pub get
flutter run -d macos        # 또는 -d windows / -d linux
```

- **데스크톱은 파일 우선 로드다.** `lib/presentation/host/bundle_asset_source.dart:22-27` 이
  `if (!kIsWeb && await File(path).exists())` 로 **디스크 파일을 번들보다 먼저** 읽는다.
  → `tools/mapEditor` 가 `assets/maps/Map016.json` 을 고치거나 `assets/Map016.cm2` 를 손으로 고쳐도
  **재빌드 없이** 다음 맵 진입부터 반영된다.
- `File(path)` 는 **상대 경로**이므로 반드시 `hadar2026_app/` 를 작업 디렉토리로 두고 실행할 것.
  다른 디렉토리에서 띄우면 조용히 번들(= 빌드 당시 스냅샷)을 읽는다.
- **웹(`flutter build web`)에서는 파일 우선 로드가 없다** — 새로 만든 두 cm2 는 번들에 실려야 하고,
  그것은 재빌드가 필요하다. S1 의 검증은 데스크톱에서 한다.
- 조작(`docs/key_input_policy.md`): 이동 = 방향키/WASD, 확인 = Enter/E, 메뉴·취소 = Esc/Q/Space
  (Space 는 맵 모드에서만 메인 메뉴를 연다).

### 3. 세이브·로드 확인 절차

세이브 위치: **`SharedPreferences` 의 `hadar_save_<N>`** 키(`lib/application/save_manager.dart:11,27`).
메뉴 경로: 맵에서 `Space` → `게임 선택 상황` → `현재의 게임을 저장`(`menu_flows.dart:291`) → 슬롯 선택.
불러오기: `게임 선택 상황` → `이전의 게임을 재개`(`menu_flows.dart:290`) → 슬롯.
성공 시 `GameReloadException` 이 던져져 실행 루프가 풀린다(`menu_flows.dart:519,536`) — **오류가 아니다.**

| # | 절차 | 기대 결과 |
|---|---|---|
| S1 | §2 의 3번(수락)까지 진행 → 저장 → 로드 | 두람이 **"창고지기 가른에게 가 보십시오."** (진행중 대사). 초기 대사로 돌아가면 실패 |
| S2 | §2 의 5번(기름 획득)까지 진행 → 저장 → 로드 | 가른이 "남은 기름은 그것이 마지막이었네.", 두람이 수령 분기로 진입 |
| S3 | §2 의 6번(완료)까지 → 저장 → 로드 → `(10,7)` 에서 북쪽 | 봉화대 문이 **열린 상태**로 남아 있다 (맵 타일이 세이브에 실린 증거) |
| S4 | 앱을 완전히 종료하고 다시 띄운 뒤 로드 | 위 3개가 모두 동일하게 재현된다 |

> **부록 C-1 경고 — 로드 후 JSON 대사 티어가 죽는다.**
> `lib/domain/map/map_model.dart:50-58` 의 `toJson()` 에 `'events'` 가 없다. `fromJson` 도 복원하지 않으므로
> **세이브를 로드한 순간 `map.events` 는 빈 리스트**가 되고, `HDTileEventDispatcher._emitJsonDialog` 가
> 순회할 것이 사라진다 → `Map002`(18개)·`Map003`(3개)·`Map010`(8개)·`Map011`(9개)의 **정적 대사가 전부 사라진다.**
> **이 샘플은 이벤트를 하나도 만들지 않고 대사를 전부 cm2 `Talk` 로 내므로 영향이 없다**([S1-02 §3](S1-02-new-map.md)).
> **JSON `dialogLines` 에 의존하는 순간 이 결함에 물린다** — 샘플을 늘릴 때 이벤트 대사를 쓰지 말 것.
> 수리는 [P0-07](../P0-foundation/P0-07-save-drops-map-events.md).
>
> **부록 C-2 부수 효과 — 로드 후에도 cm2 는 살아 있다.**
> `save_manager.dart:86` 은 `setNewMap` 을 직접 부르므로 `HDGameSession.currentMapCm2Path` 가 **갱신되지 않는다.**
> 그러면 디스패처는 cm2 티어 대신 **legacy 분기**(`tile_event_dispatcher.dart:148-156`)를 타는데,
> 그 분기도 엔진을 실행한다. 그리고 엔진에는 `Map016.cm2` 가 그대로 들어 있다 —
> 세이브가 `gameOption.scriptFile`(= `assets/Map016.cm2`, `script_engine_adapter.dart:108`)을 기록하고
> 로드가 그것을 다시 읽기 때문이다(`save_manager.dart:66-70`). **즉 NPC 는 로드 후에도 말한다.**
> 단 legacy 분기는 **JSON 을 cm2 보다 먼저** 내므로 `Event::Override()` 로 억제할 수 없다.
> 이벤트가 0개인 이 맵에서는 무해하지만, **이 조합이 안전한 이유를 알고 의존하는 것**과 모르는 것은 다르다.

### 4. 막혔을 때의 원칙

**고치지 않는다.** [S1-99](S1-99-friction-log.md) 에 기록하고 우회한다. 이 구간은 **코드 변경 0** 이다.

- NPC 가 침묵한다 → 콘솔에서 `Unknown function` / `Unknown command` 를 먼저 찾는다. 다음으로
  `On(x,y)` 좌표와 objUpper 배치 좌표를 대조한다([S1-02 §4](S1-02-new-map.md)).
- 대사가 초기 상태로 되돌아간다 → `.assign` 이 메인 스크립트에 있는지 본다([S1-03 §4 ③](S1-03-quest-cm2.md)).
- 아무 반응이 없다 → `Loading script content from assets/Map016.cm2` 가 찍혔는지 본다.
  안 찍혔으면 직전 맵의 스크립트가 돌고 있다(부록 A-2 → [P0-03](../P0-foundation/P0-03-cm2-load-state-leak.md)).
- 우회가 불가능해 **데이터만으로는 끝낼 수 없다**고 판단되면, 그 판단 자체를 S1-99 에 근거와 함께 적고
  P0 백로그의 해당 이슈를 [BOARD](../BOARD.md) 에서 끌어온다. **여기서 코드를 고치지 않는다.**

## 완료 판정 기준

[MILESTONES §2](../MILESTONES.md) 의 6개를 그대로 가져온다:

- [ ] 새 맵을 **이름으로** 진입할 수 있다
- [ ] NPC 3명이 각각 말한다. 그중 최소 1명은 **퀘스트 상태에 따라 다른 말**을 한다
- [ ] 의뢰 수락 → 물건 획득 → 전달 → 보상의 **전 과정이 플레이로 완주**된다
- [ ] 각 단계가 플래그로 기록되고, **중간에 세이브·로드해도 진행이 유지**된다
- [ ] 완료 후 다시 말을 걸면 **완료 상태의 대사**가 나온다
- [ ] **저작 중 막힌 지점을 전부 기록**했다 → [S1-99](S1-99-friction-log.md)

추가로 이 이슈가 관측할 것:

- [ ] §3 의 S1~S4 네 행이 전부 기대 결과와 일치한다
- [ ] 완주 중 콘솔에 `Unknown command` / `Unknown function` 이 한 줄도 없다
- [ ] `git status` 에 나타난 변경이 **`Map016.json` · `Map016.cm2` · `flag4quest1.cm2` · `MapInfos.json` ·
      `Map002.json` · `Map002.cm2`** 6개뿐이고, `lib/` 아래 변경이 **0** 이다

## 하지 않을 것

- 코드 변경. 부록 C-1·C-2·A-2 의 수리(→ P0 백로그).
- 웹 빌드 검증, 자동화 테스트·헤드리스 하네스 작성.
- 두 번째 완주 경로(실패 분기·거절 분기)의 전수 검증 — 거절 후 재수락만 확인하면 충분하다.
